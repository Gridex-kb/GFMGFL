# HTML 슬라이드

`gfm-gfl-slides.html`은 GFM/GFL 지식창고를 17장으로 요약한 발표 자료입니다. 파일 하나에 스타일, 스크립트, EMT 시뮬레이션 데이터가 모두 들어 있어 인터넷 연결 없이 브라우저로 열 수 있습니다.

## 사용법

| 동작 | 키 |
|---|---|
| 다음 / 이전 | → / ←, 스페이스, PageDown / PageUp, 스와이프 |
| 처음 / 끝 | Home / End |
| 밝은·어두운 테마 | T 또는 오른쪽 아래 "테마" 버튼 |
| 특정 장으로 이동 | 주소 끝에 `#11` 처럼 번호 |
| PDF 저장 | 브라우저 인쇄 → PDF (장당 한 페이지) |

- EMT 결과 장(11~15장)의 그래프는 마우스를 올리거나 터치하면 시각별 값을 보여줍니다.
- 폭 760 px 이하 화면에서는 모든 장이 세로로 이어져 스크롤로 읽습니다.

## 구성

| 장 | 내용 |
|---|---|
| 1~9 | 표지, 배경, 정의, 제어 구조, GFM 기능, 비교표, 표준 타임라인, 국내 요건, 실증 |
| 10~15 | EMT 모델, 위상 점프, RoCoF, 약계통·안정도 맵, 고장, 단독운전 |
| 16~17 | 모델링 교훈, 사업자 체크리스트 |

## 데이터 갱신

슬라이드의 그래프 데이터는 HTML 안의 `/*EMT_DATA_START*/ … /*EMT_DATA_END*/` 구간에 들어 있습니다. 시뮬레이션을 다시 돌리면 이 구간이 자동으로 바뀝니다.

```bash
cd simulation/emt
python run_scenarios.py
```

본문 수치(표, 설명 문장)는 자동으로 바뀌지 않으므로 `simulation/emt/results/summary.md`와 대조해 손으로 고칩니다.
