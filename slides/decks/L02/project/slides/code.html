import itertools, numpy as np
V_dc = 2.256
a = np.exp(2j*np.pi/3)
for s in itertools.product((1, 0), repeat=3):
    vp = (2*np.array(s) - 1)*V_dc/2 # 극전압
    vn0 = vp.mean() # 영상분
    vph = vp - vn0 # 상전압
    v = 2/3*(vp[0] + a*vp[1] + a**2*vp[2])
    print(s, vn0, vph[0], abs(v), np.angle(v, deg=True))

이제 Python으로 여덟 상태 표를 만들어 봅니다. itertools.product로 세 레그의 0과 1 조합 여덟 개를 돌면서, 극전압, 영상분, 상전압, 공간벡터를 차례로 계산합니다. 극전압은 2S − 1에 V_dc/2를 곱한 것, 영상분은 평균, 상전압은 그 차이, 공간벡터는 1강의 정의 그대로입니다. 출력의 일부를 오른쪽에 적었습니다. 예제 1에서 손으로 구한 110의 값이 그대로 나옵니다. 해 볼 것 두 가지입니다. 첫째, 극전압 대신 상전압으로 공간벡터를 계산해서 같은 값이 나오는지 assert로 확인해 보세요. 영상분이 αβ에 안 보인다는 것을 코드로 증명하는 겁니다. 둘째, 선간전압이 세 값뿐인지 확인해 보세요. 교재 C03 실습에는 시뮬레이션 모델의 pwm 함수를 직접 호출하는 실습 2도 있습니다.
