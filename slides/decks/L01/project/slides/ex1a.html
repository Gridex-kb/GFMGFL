30° 늦은 전류 = 길이 1, 각도 −30°의 멈춘 화살표

결과값 [pu]
id = cos 30°0.866
iq = −sin 30°−0.5
P = vd id0.866
Q = −vd iq0.5 (내보냄)

1강 · 3상 계통의 표현과 공간벡터·dq

23 / 27

풀이입니다. 평형 3상 전류의 공간벡터는 2부에서 본 것처럼 진폭 곱하기 e의 j(위상)입니다. 진폭 1, 위상 ωt − 30도이니 e의 j(ωt − 30°)입니다. 여기에 e의 −jωt를 곱하면 ωt가 지워지고 e의 −j30°, 즉 0.866 − j0.5가 남습니다. 그래서 id는 0.866, iq는 −0.5입니다. 전압은 d축에 맞췄으니 vd = 1, vq = 0입니다. P는 vd id로 0.866, Q는 −vd iq로 0.5입니다. 역률 cos 30도가 0.866인 것과 맞습니다. Q가 양수이니 이 규약에서는 무효전력을 내보내는 쪽입니다. 오른쪽 그림이 같은 전류를 세 단계로 본 것입니다. 맨 위 abc는 사인파 세 개, 가운데 알파베타는 사인파 두 개, 맨 아래 dq는 직류 두 개입니다. 도입에서 물었던 PI 문제가 이렇게 풀립니다. 맨 아래 직류 두 개를 PI로 제어하면 됩니다.
