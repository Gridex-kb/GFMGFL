d축을 전압에 맞추면 P와 Q가 따로 제어된다

id → 유효전력 P

전압과 같은 방향의 전류 성분

−iq → 무효전력 Q

전압보다 90° 늦은 전류 성분 (iq < 0 이면 Q > 0)

1강 · 3상 계통의 표현과 공간벡터·dq

pu 전력식 P = Re(v i*)에 v = vd + j vq, i = id + j iq를 넣고 풀면 왼쪽 식이 나옵니다. P는 vd id + vq iq, Q는 vq id − vd iq입니다. 칠판에서 켤레 복소수 곱을 전개해 보겠습니다. 여기서 θ를 잘 고르면 식이 아주 단순해집니다. d축을 전압 벡터 방향에 맞추면 vq가 0이 되고, P는 vd id, Q는 −vd iq가 됩니다. 즉 id를 지령하면 유효전력을, iq를 지령하면 무효전력을 따로따로 정할 수 있습니다. 부호에 주의하세요. 이 강좌의 규약에서 iq가 음수이면 전류가 전압보다 늦고, 무효전력을 내보내는 방향입니다. GFL 제어기가 PLL로 d축을 계통 전압에 맞추는 이유가 바로 이것입니다.
