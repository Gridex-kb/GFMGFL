위상 점프 전력과 드룹 응답을 계산하라

주어진 것 Xv = 0.3 pu, E = V = 1 pu, H = 4 s, D = 50, f0 = 60 Hz

(1) SCR 5, P0 = 0.5 pu에서 계통 위상이 −10° 뛰면 위상 점프 전력은 (페이저 근사)?

(2) 계통 주파수가 0.3 Hz 떨어지면 정상상태 ΔP는? 같은 동특성을 드룹 + LPF로 만들려면 mp와 차단주파수는?

(3) GFM이 P를 측정하면서도 위상 점프 응답이 “측정 기반이 아니다”라는 말이 성립하는 이유는?

예제입니다. 첫째, SCR 5, 가상 리액턴스 0.3, E와 V가 1 pu, 운전점 0.5 pu에서 계통 위상이 −10도 뛰면 위상 점프 전력은 페이저 근사로 얼마일까요. 둘째, H 4초, D 50인 VSM이 계통 주파수 0.3 Hz 하락을 겪으면 정상상태 ΔP는 얼마이고, 같은 동특성을 드룹과 LPF로 만들려면 드룹 계수와 필터 차단주파수는 얼마일까요. 셋째, GFM이 P를 측정하는데도 위상 점프 응답이 측정 기반이 아니라는 말이 어떻게 성립하는지 가상 인덕턴스 식으로 설명해 보세요. 5분 드리겠습니다.
