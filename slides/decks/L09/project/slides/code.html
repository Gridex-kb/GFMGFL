실습 파일입니다. practice 폴더의 lec09 파일에 실습이 다섯 개 있습니다. 1번은 고장 시 가상 임피던스 전류, 2번은 원형 포화와 전력 상한, 3번은 평형점 조건, 4번은 2.0 pu 고장전류의 전압 여유 검산입니다. 5번이 --emt 옵션으로 평균값 모델을 돌리는 실습입니다. 화면 위 코드처럼 계통 전압 0.3 pu 150 ms 고장을 보정 유무로 돌려 최대 위상 이탈, 제거 후 포화 지속, 유효전력 회복 시간을 비교하고 GFL과도 비교합니다. 아래 코드는 PCC 지락 200 ms에 전류 한계 1.2와 2.0을 넣어 2.0 pu 이상 지속 시간을 셉니다. 약 2분 걸립니다. 해 볼 것으로, 관성 H를 4에서 2초로 줄이면 회복 시간이 어떻게 바뀌고 고장 후 스윙이 커지는지, 고장 컨덕턴스를 20에서 3 pu로 낮춰 고장 저항이 커지면 1.2 사양의 전류가 한계 안에 머무는 조건을 찾아보세요. 그 경우 GFM은 전압원 그대로입니다. 또 전압 제어 이득을 5에서 1로 낮춰 고장 후 과전압이 줄어드는지도 확인해 보세요.
