실습 파일입니다. practice 폴더의 lec10 파일에 실습이 여섯 개 있습니다. 1번은 보고서 JSON을 읽어 판정표와 부적합 근거 항목을 훑는 것입니다. 화면 위 코드처럼 tests 목록의 verdict와 criteria를 읽으면 됩니다. 2번은 위상점프 전력 예상과 T07 세 시간 기준, 3번은 관성 전력과 등가 관성, 4번은 감쇠비를 보고서 계열의 극값 비로 다시 구하는 것, 5번은 T13 지속 시간과 T01 분리 후 주파수입니다. 6번이 --emt 옵션으로 시험 하나를 평균값 모델로 돌리는 실습입니다. compliance_tests 모듈의 TESTS 정의와 label_params, scenario, 그리고 보고서와 같은 판정 함수 eval_vstep, eval_phase를 그대로 빌려 씁니다. 평균값 10 µs로 T10은 GFL 88.3 ms 부적합, GFM 4.3 ms 적합이고, T07의 GFM은 플러스 0.68 pu, 8.2 ms, 3.1 ms로 스위칭 모델 보고서와 같은 결론입니다. 약 2분 걸립니다. 해 볼 것으로, 주석 처리된 줄을 풀어 GFL의 PLL을 50 Hz로 올려도 세 기준이 여전히 부적합인지, T01에서 드룹을 0.04로 바꾸면 분리 후 주파수가 59.28 Hz로 가는지 확인해 보세요.
