# 제조사·제품 현황

> 요약: GFM 기능을 제공하는 PCS/인버터·풍력·HVDC·STATCOM 제조사와 제품명, 첫 GFM 적용 연도, 인증 현황을 정리한다. 제조사 보도자료 기반 수치는 (제조사 주장)이다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- GFM은 제품이 아니라 **제어 모드**다. 제조사마다 이름이 다르다: Tesla "Virtual Machine Mode", SMA "Grid Forming", Hitachi Energy "Virtual Synchronous Machine", Sungrow "Stem-Cell Grid-Forming", Huawei "Smart String Grid-Forming".
- 공식 계통코드 적합이 확인된 사례: **GB GC0137 — SMA**(Blackhillock·Kilmarnock South). **독일 VDE FNN** 인증 — SMA(2025-09 유닛인증, 2026-10 가이드라인 2.1 프로토타입), Sungrow(2026-07 프로토타입). **중국 CEPRI** GFM 성능시험 — Kehua(2024 최초).
- 국내: LS일렉트릭(10 MW급 검증), 효성중공업(기본기능 인증), HD현대일렉트릭(4 MW급 개발), 한국그리드포밍(250 kW급 실증).

## 4. 조달 시 확인 항목

- [ ] GFM 모드 명칭과 제어 계열(Droop/VSM/기타), 상시 GFM인지 전환형인지
