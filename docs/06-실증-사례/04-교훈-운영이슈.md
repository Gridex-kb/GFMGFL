# 교훈과 운영 이슈

> 요약: 실증·상업운전에서 보고된 정량 성과, 제조사가 공개한 교훈, 프로젝트 지연 원인, 진동·상호작용 사례, 시장·정책 교훈을 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- **GFM은 실계통에서 효과가 확인됐다**: Hornsdale 약 2,000 MWs 관성, Kapolei 250 ms 내 50 MW 응답, Kauai GFL→GFM 전환 후 주파수 진동 소멸, Dalrymple 반복 섬운전·재동기 성공.
- **모델과 실물의 차이**가 반복 보고된다. 실제 계통 이벤트 데이터로 모델을 검증해야 한다(Tesla, AEMO, HECO 공통).
- **IP·모델 공개 문제**가 접속 지연을 일으켰다(Broken Hill). 조달 계약에 모델 제공 조건을 명시해야 한다.
- GFL 기반 진동(호주 West Murray)은 GFM 자원으로 완화되고 있으나, GFM–GFM, GFM–GFL 상호작용에 대한 공식 사고보고서는 아직 확인되지 않았다.

## 2. 제조사·사업자가 공개한 교훈

### Tesla (ESIG 2025)
1. 서드파티 플랜트 컨트롤러와의 통신·제어 문제가 현장 커미셔닝에서 처음 발견되는 경우가 많다 → **CHIL 사전시험 필수**.
2. 모델과 실플랜트 거동이 다를 수 있다 → 실제 계통 이벤트 데이터로 검증(NERC MOD-027 활용).
3. 계측기 고장 등 엣지케이스에서 0 MW/0 MVAr로 완만히 램프다운하는 등 **고장 모드를 명시적으로 시험**해야 한다.
[ESIG 발표](https://www.esig.energy/attachment/serve/session-1a-megapack-grid-forming-sarah-walinga-and-ali-mohammadpour-2)

### Dalrymple (AEMO/ElectraNet)
- 피더 복귀 시 벡터시프트 보호가 트립을 유발 → 보호 정정과 GFM 과도 거동의 협조 필요. 여름 고온에 성능 민감. [RenewEconomy](https://reneweconomy.com.au/south-australias-second-big-battery-takes-peninsula-off-grid-as-tests-continue-83320)
- EMT 모델이 과도 거동 일부를 재현 못함(부하 동특성 미모델링 추정). [ESIG](https://www.esig.energy/working-groups/reliability/grid-forming-landscape/grid-forming-performance-in-real-time/dalrymple/)

### Broken Hill (AGL)
- GFM 인버터의 핵심 IP(모델)가 사업자·컨설턴트에게 제공되지 않아 접속·검증이 약 1년 지연. [RenewEconomy](https://reneweconomy.com.au/pioneering-broken-hill-battery-shows-first-signs-of-life-after-months-of-connection-delays/) · [ARENA 교훈 보고서](https://arena.gov.au/knowledge-bank/agl-broken-hill-grid-forming-battery-lessons-learnt-report-1)

### Liddell (AGL)
- "섬운전 커미셔닝과 배터리 과설계" 교훈 세션 개최(본문 접근 불가, 확인 필요). [energy-storage.news](https://www.energy-storage.news/island-commissioning-to-battery-oversizing-key-lessons-from-agls-1gwh-grid-forming-liddell-bess-in-australia/)

### OSMOSE (RTE)
- 1 MVA 데모가 커미셔닝 중 화재로 실운전에 이르지 못한 실패 사례. [SINTEF](https://www.sintef.no/globalassets/project/hvdc-pro/prevost_inertia_management_tso_perspective.pdf)

## 4. 시장·정책 교훈

- AEMO: GFM BESS가 NEM 시스템강도 요건 최상위 등급을 충족하는지 아직 확인되지 않음(2025). 성능 등급 체계와 검증 방법이 과제. [energy-storage.news](https://www.energy-storage.news/australias-grid-forming-battery-storage-pipeline-extends-to-nearly-a-hundred-projects-says-aemo/)
- ESIG(2025): 신규 대형 배터리에 GFM 소프트웨어를 지금 탑재하면 후속 인프라 비용을 절감한다고 권고. [pv magazine USA](https://pv-magazine-usa.com/2025/09/18/deploy-grid-forming-batteries-now-to-avoid-costly-infrastructure-later-says-esig)
- 영국 2026 2차 안정도 입찰에서 GFM BESS 낙찰이 없었다는 보도가 있어 시장 설계와 가격 경쟁력이 변수 (원문 확인 필요). [ess-news](https://www.ess-news.com/2026/01/23/zenobe-more-than-doubles-synthetic-inertia-capability-with-second-grid-forming-bess-in-scotland)
- 한국: GFM은 배터리보다 PCS·인버터 제어기술에 좌우되며 추가비용과 기술성숙도가 쟁점. [노컷뉴스](https://en.nocutnews.co.kr/news/6546553)

## 5. 사업자 체크리스트 (교훈 반영)

- [ ] 계약서에 EMT 모델·파라미터 제공 범위와 IP 조건 명시
- [ ] 플랜트 컨트롤러–PCS 간 CHIL 사전시험 일정 확보
- [ ] 보호 정정(벡터시프트, RoCoF, 과전류)과 GFM 과도 거동 협조 검토
- [ ] 계측기 고장 등 엣지케이스 고장 모드 시험
- [ ] 고속 기록장치로 이벤트 데이터 수집, 모델 재검증 체계
- [ ] 고온 환경 성능 디레이팅 확인
- [ ] 섬운전 커미셔닝 절차와 재동기 조건 사전 합의
