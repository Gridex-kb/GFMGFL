# 계통연계 인버터의 기본 구조와 제어 계층

> 요약: 전압형 컨버터(VSC)의 하드웨어, 필터, 좌표변환, 제어 계층 구조 등 GFL/GFM 양쪽에 공통인 기초를 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- 계통연계 인버터(PCS)는 DC 전원 → **전압형 컨버터(VSC)** → **LCL 필터** → 변압기 → 계통 구조다. 반도체 스위칭으로 만든 PWM 전압이 필터를 거쳐 정현파가 된다.
- 제어는 보통 **외부 루프(전력/전압/동기화) → 내부 루프(전류) → PWM** 계층으로 나뉜다. GFL과 GFM의 차이는 거의 **외부 루프와 동기화 방식**에 있다.
- 제어는 대부분 **dq 동기좌표계**에서 수행한다. 좌표 변환의 기준 각 $\theta$를 "어디서 얻느냐"가 GFL(PLL)과 GFM(자체 생성)을 가른다.

## 1. 하드웨어

```
 DC (배터리/PV/정류기)
   │
 ┌─┴─┐  DC링크 커패시터 (C_dc)
 │VSC│  IGBT/SiC 2-level 또는 3-level(NPC) 브리지, PWM 2~20 kHz
 └─┬─┘
   L_f  ─┬─ C_f ─┬─ L_g ─── 변압기 ─── PCC ─── 계통
 (LCL 필터, 스위칭 고조파 제거)          (Point of Common Coupling)
```

- **과전류 한계**: 반도체의 열 한계 때문에 통상 정격의 1.1~1.5 pu(순간 2 pu 이하). 동기기(5~7 pu)와의 가장 큰 물리적 차이이며 GFM 설계의 핵심 제약이다.
- **DC링크**: 에너지 버퍼. 관성 응답 전력을 내려면 DC측 전원(배터리)이 받쳐 줘야 한다. PV만 있는 경우 출력을 일부 줄여(curtailment) 여유를 둬야 상향 응답이 가능하다.
- **필터 공진**: LCL 공진 주파수(수백 Hz~수 kHz)는 전류제어 대역·능동댐핑 설계에 영향을 준다.

## 2. 좌표 변환 (Clarke / Park)

3상 $abc$ → 정지 $\alpha\beta$ (Clarke) → 회전 $dq$ (Park, 각 $\theta$).

$$\begin{bmatrix} v_d \\ v_q \end{bmatrix} = \begin{bmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{bmatrix} \begin{bmatrix} v_\alpha \\ v_\beta \end{bmatrix}$$

- $dq$ 좌표에서 정상상태 정현파는 DC 값이 되어 PI 제어기로 무정상오차 제어가 가능하다.
- $\theta$ 정렬 관례: d축을 계통 전압에 맞추면 $v_q = 0$, 이때 $P = \frac{3}{2} v_d i_d$, $Q = -\frac{3}{2} v_d i_q$.
- **GFL**: $\theta$ = PLL 출력. **GFM**: $\theta$ = 전력 동기화 루프(Droop/VSM 등)의 적분 출력.

## 3. 제어 계층

| 계층 | 시간 스케일 | GFL | GFM |
|---|---|---|---|
| 상위(플랜트/EMS) | 초~분 | P, Q 지령 | P, Q, V, f 설정값 |
| 외부 루프 | 수십~수백 ms | PLL + P/Q → $i_{dq}^*$ 계산 | **전력 동기화**(P–f) + **전압 제어**(Q–V) → $v^*$ 또는 $i^*$ |
| 내부 루프 | 수 ms | dq 전류 PI (+ 디커플링, 피드포워드) | 전압 루프 → 전류 루프 (캐스케이드) 또는 전압 직접 출력 |
| 변조 | 수십 µs | SPWM/SVPWM | 동일 |

### 내부 전류 루프 (공통)

$$v_d^* = v_d + \big(K_p + \tfrac{K_i}{s}\big)(i_d^* - i_d) - \omega L i_q, \qquad v_q^* = v_q + \big(K_p + \tfrac{K_i}{s}\big)(i_q^* - i_q) + \omega L i_d$$

대역폭은 통상 스위칭 주파수의 1/10~1/20. GFM에서는 이 루프가 **전류 제한**을 구현하는 자리이기도 하다.

## 4. 모델링 관점: 전류원 vs 전압원

```
 GFL 등가 (전류원)             GFM 등가 (전압원)
     ┌───┐                      ┌───┐  Z_v (가상 임피던스)
 I*──│ ↑ │──┬── PCC          E∠δ ─│ ~ │────┬── PCC
     └───┘  │                   └───┘     │
            Y_out(s)                   Z_out(s)
```

- 임피던스 기반 안정도 해석: GFL의 출력 어드미턴스 $Y_{out}(s)$와 계통 임피던스 $Z_g(s)$의 비 $Z_g Y_{out}$ 에 Nyquist 판별을 적용. 저주파 대역에서 PLL이 **음저항(negative resistance)** 특성을 만들어 약계통 불안정의 원인이 된다.
- GFM은 저주파에서 유도성 출력 임피던스를 가지므로 계통 임피던스와 수동(passive)적으로 결합한다.

## 5. 시뮬레이션 도구와 모델 종류

| 모델 종류 | 특징 | 용도 |
|---|---|---|
| EMT (PSCAD, EMTP-RV, PowerFactory EMT, RTDS, HYPERSIM) | 스위칭 또는 평균 모델, µs 단위 | GFM 제어 검증, 약계통 상호작용, 고장 응답 |
| RMS/정현 근사 (PSS/E, PowerFactory RMS) | 기본파 페이저, ms 단위 | 대규모 계통 안정도 (단, GFM 전류제한·PLL 동역학은 근사) |
| 제조사 블랙박스 EMT 모델 | 실제 제어 코드 포함 (DLL) | 계통운영자 연계 검토 (AEMO, ERCOT 등 요구) |
| 범용 GFM 모델 (WECC REGFM_A1, REGFM_B1) | 공개 파라미터화 모델 | 계획 연구, 표준화 |
