# 동기발전기, 관성, 계통강도(SCR)

> 요약: GFM/GFL을 이해하기 위한 전력계통 기초 — 동기발전기의 동작, 관성과 스윙 방정식, 단락비(SCR)와 계통강도를 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- 동기발전기는 **회전자 각도 $\delta$** 와 **기전력 $E$** 로 전력을 결정하는 전압원이다. $P \approx \dfrac{EV}{X}\sin\delta$.
- 관성상수 $H$[s]는 정격용량 대비 회전자 운동에너지. 계통 전체 관성이 작아지면 외란 시 주파수 변화율(RoCoF)이 커진다.
- 단락비 $SCR$은 연계점의 "계통이 얼마나 단단한가"의 지표. GFL은 낮은 SCR에서 불안정해지고, GFM은 SCR을 높이는 쪽으로 기여한다.
- 복수 IBR이 모인 지역에서는 단일 SCR 대신 **WSCR, CSCR, ESCR** 같은 보정 지표를 쓴다.

## 1. 동기발전기의 전력 전달

내부 기전력 $E\angle\delta$, 단자(계통) 전압 $V\angle 0$, 둘 사이 리액턴스 $X$일 때

$$P = \frac{EV}{X}\sin\delta, \qquad Q = \frac{EV\cos\delta - V^2}{X}$$

- 유효전력은 주로 **위상차 $\delta$** 로, 무효전력은 주로 **전압 크기 차** 로 결정된다. GFM 제어의 P–f, Q–V 분리는 이 관계에서 나온다.
- 동기화 토크 계수 $\partial P/\partial\delta = \frac{EV}{X}\cos\delta$ 가 양수일 때 안정. 이것이 여러 전압원이 "저절로" 동기화되는 이유다.

## 2. 스윙 방정식과 관성

$$\frac{2H}{\omega_0}\frac{d\omega}{dt} = P_m - P_e - D(\omega-\omega_0)$$

- $H = \dfrac{J\omega_0^2}{2S_n}$ [s], 통상 화력 3~6 s, 수력 2~4 s, 가스터빈 4~6 s.
- $D$: 댐핑 계수. 제동권선·부하 주파수 특성 등.
- 계통 전체 관성: $H_{sys} = \sum H_i S_i / \sum S_i$. **RoCoF 초기값** $\approx \dfrac{\Delta P}{2H_{sys}} f_0$.

GFM의 VSM(가상동기기) 제어는 이 식을 그대로 소프트웨어로 구현하며, $H$와 $D$는 설계 파라미터가 된다. → [GFM 제어기법](../03-GFM/02-GFM-제어기법.md)

### 관성 응답과 1차 주파수제어의 시간대

```
0 ms      ~수백 ms            수 초 ~ 30 s        수 분
|-- 관성 응답 --|-- FFR/빠른 응답 --|-- 1차 주파수제어 --|-- 2차(AGC) --|
   (GFM, 동기기)   (GFL 측정기반)      (거버너, ESS)
```

## 3. 계통강도와 단락비(SCR)

$$SCR = \frac{S_{sc}}{S_{IBR}} = \frac{V^2 / Z_{th}}{S_{IBR}}$$

- $S_{sc}$: 연계점 3상 단락용량, $Z_{th}$: 테브난 등가 임피던스, $S_{IBR}$: 연계 IBR 정격.
- 경험적 분류 (IEEE/CIGRE 관례): **SCR > 3 강계통, 2~3 약계통, < 2 매우 약계통**. GFL 인버터의 안정 한계는 제어 설계에 따라 다르지만 보통 SCR 1.5~2 부근에서 어려워진다.
- X/R 비도 중요하다. 배전급(X/R 낮음)에서는 유·무효전력 결합이 강해 Droop 설계가 달라진다.

### 복수 IBR 보정 지표

| 지표 | 정의 요지 | 용도 |
|---|---|---|
| WSCR (Weighted SCR) | 전기적으로 가까운 IBR들을 묶어 가중 평균 | ERCOT 파네들(Panhandle) 지역 분석에서 도입 |
| CSCR (Composite SCR) | 묶은 IBR 전체를 하나의 모선으로 보고 단락용량 계산 | 다수 IBR 집중 지역 |
| ESCR (Effective SCR) | 다른 IBR의 영향(상호작용 계수)을 임피던스 행렬로 반영 | 다수 HVDC/IBR |
| Grid strength impedance metric | 임피던스 행렬 기반 일반화 | 최근 연구/일부 계통운영자 |

호주 AEMO는 지역별 "system strength 요건"을 정량화해 발전사업자에게 비용을 분담시키고, 동기조상기 또는 GFM으로 충족하게 하는 제도를 운영한다. → [국제 표준·계통코드](../05-표준-계통코드/01-국제표준-해외계통코드.md)

## 4. GFM이 계통강도에 미치는 영향

- GFM은 임피던스 뒤의 전압원이므로 외부에서 보면 테브난 임피던스를 **낮춘다** → 주변 GFL의 유효 SCR이 상승.
- 다만 GFM 전류 한계(1.2~2 pu)가 동기기(5~7 pu)보다 작아, 단락전류 기여는 용량 대비 제한적이다. 보호 관점의 "단락전류"와 안정도 관점의 "전압 강성"을 구분해야 한다.
- AEMO·NGESO 등은 GFM BESS를 **동기조상기의 대안**으로 인정하되, 기여량은 EMT 시뮬레이션으로 개별 평가한다.
