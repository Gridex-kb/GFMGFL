# 한국 — 2027년 BESS GFM 요건과 국내 제도

> 요약: 2026-06-24 기후에너지환경부·한전·전력거래소가 발표한 GFM 성능요건, 적용 대상·시점, 관련 규정(송·배전용 전기설비 이용규정, 전력시장운영규칙), 중앙계약시장 연계, 한전 연계기준안의 공개된 수치, 시험·검증·인증 체계와 미확인 사항을 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안 (공식 조문 미공개, 보도·발표자료 기반)

## 핵심 요약 (TL;DR)

- **발표**: 2026-06-24 기후에너지환경부가 한전·전력거래소·학계·제작사와 협의해 "국내 송전계통 환경에 부합하는 그리드포밍 성능 요건"을 마련했다고 발표. [전기신문](https://www.electimes.com/news/articleView.html?idxno=369476)
- **적용**: 2027년 12월 상업운전 예정인 중앙계약시장 장주기 BESS(2차 입찰 540 MW)부터. 이후 2028년 540 MW, 2029년 600 MW에도 적용(11차 전기본 기준 총 1,680 MW). [솔라투데이](https://www.solartodaymag.com/news/articleView.html?idxno=20790)
- **근거 규정**: 사업자는 「송·배전용 전기설비 이용규정」과 「전력시장운영규칙」에 따라 성능 요건과 운영 기준을 준수. [전기신문](https://www.electimes.com/news/articleView.html?idxno=369476)
- **공개된 구체 수치**: 정부 보도자료에는 없다. 2026-04-09 전력전자학회 포럼에서 한전이 발표한 **연계기준안**이 가장 구체적: ① 고장 시 전압원 동작, ② 순시 고장전류 2.0 pu 이상을 140 ms 이상 유지, ③ 실시간 SCR 추정 기반 GFL↔GFM 무결절 자동 전환, ④ 최적화된 가상관성 상수. [E2뉴스](http://www.e2news.com/news/articleView.html?idxno=329371) (초안이며 확정 조문은 확인 필요)
- **시험·검증 체계**: 한전이 2026년 11월까지 시험·검증 체계 완비, 2027년 실계통 운전 목표. [SK E&S 뉴스](https://www.skenews.kr/news/articleView.html?idxno=53032)
- **2026년 입찰**(2026-09-22 공고, 육지 1,100 MW·제주 80 MW)에도 GFM 인버터 요건이 신규 포함. [전기신문](https://www.electimes.com/news/articleView.html?idxno=372837)

## 2. 요건 내용 (공개된 범위)

### 2.1 정부 발표(2026-06-24)
- 성능 요건의 범주: 전압원 역할, 가상관성 제공, 계통강도 확보, 순시 고장전류 대응(대한경제 보도 기준). [대한경제](https://m.dnews.co.kr/m_home/view.jsp?idxno=202606261201447330894)
- 구체 수치는 보도자료에 공개되지 않았다. 이재식 전력망정책관은 "성능 요건을 보다 강화해 나가겠다"고 밝혔다. [전기신문](https://www.electimes.com/news/articleView.html?idxno=369476)

### 2.2 한전 연계기준안 (2026-04-09 포럼, 초안)
| 항목 | 내용 |
|---|---|
| 고장 시 거동 | 전압원으로 동작 |
| 순시 고장전류 | **2.0 pu 이상, 140 ms 이상 유지** |
| 모드 전환 | 실시간 SCR 추정 기반 GFL↔GFM 자동 무결절 전환 |
| 관성 | 최적화된 가상관성 상수 |
출처: [E2뉴스](http://www.e2news.com/news/articleView.html?idxno=329371). 전력시장운영규칙 개정안의 실제 의결 조문은 (확인 필요).

- 비고: "GFL↔GFM 자동 전환"을 허용하는 점은 상시 GFM 특성을 요구하는 GB·AEMO 규격과 차이가 있다. 전환형의 장단점은 [하이브리드·혼합 계통](../04-비교/02-하이브리드-혼합계통.md) 참고.
- 2.0 pu/140 ms 고장전류 요건은 NERC(정격 초과 고장전류 요건 미부과)·MISO(core만 채택)보다 하드웨어 부담이 큰 쪽이다. → [국제 비교](01-국제표준-해외계통코드.md)

### 2.3 KPX 발표 일정·현황 (동일 포럼)
- 2027년까지 제작사 모델 반영 계통영향평가, 2028년까지 대규모 실증.
- 국내 시험설비 최대 2 MW(제작사는 2.5 MW 이상 제작 중). KPX 제주 실증 500 kW(2024), 한국그리드포밍 광양 마이크로그리드 110 kVA GFM BESS 상업운전.
- 비용 추정: BESS 인버터 GFM 추가비 약 2,000만 원/MW vs 동기조상기 약 2억 원/MVar.
[E2뉴스](http://www.e2news.com/news/articleView.html?idxno=329371)

### 2.4 KPX가 밝힌 남은 과제 (2026-09-17)
GFM 성능수준 표준화, EMT 기반 계통해석 실용화, 다수 인버터 상호작용 모델링, 보호계전·단락전류 특성 재정립, 블랙스타트. [SK E&S 뉴스](https://www.skenews.kr/news/articleView.html?idxno=53032)
