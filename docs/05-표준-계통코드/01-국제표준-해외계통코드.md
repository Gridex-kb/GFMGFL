# 국제 표준 및 해외 계통코드

> 요약: 미국(NERC, IEEE 2800 계열, ERCOT, MISO, HECO, UNIFI, ESIG), 영국(GC0137, Stability Pathfinder, Stability Market), EU(RfG 2.0, ENTSO-E TG GFC, 독일 VDE FNN·Momentanreserve, 핀란드, 아일랜드), 호주(AEMO 자발적 규격, 시험 프레임워크, 시스템강도), 중국(국가표준)의 GFM 정의와 요건을 정리한다. 수치·일자는 문장 끝 출처 기준.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- **정의의 수렴**: 모든 기관이 "짧은 시간대에 내부 전압 페이저(크기·위상)를 거의 일정하게 유지하는 **임피던스 뒤의 전압원**"으로 수렴하며, 제어 토폴로지가 아닌 **성능·시험 기반**으로 판정한다(NERC 2023 명시). "전류·에너지 한계 내에서"라는 조건은 공통.
- **의무화 흐름**: ERCOT(2026-04-01 이후 접속계약 ESR 의무), MISO(신규 송전연계 BESS), 핀란드(약계통 D형 풍력·태양광), EU RfG 2.0(B~D형 PPM 의무 제안, 채택 대기), 중국(국가표준 2026~27 시행), 한국(2027-12).
- **시장화 흐름**: 영국 Stability Pathfinder·Mid-term Stability Market, 독일 Momentanreserve 시장(2026-01-22 개시), 호주 시스템강도 서비스.
- **시험 프레임워크**: NERC 2023 3개 시험 → AEMO 2024 7개 → ERCOT 2024 11개로 확장. 공통 핵심은 **최후 동기기 상실 생존, RoCoF, 저SCR+고장, 위상각 스텝**.

OEM 검증 EMT 모델 필수. [NERC](https://www.nerc.com/comm/RSTC_Reliability_Guidelines/White_Paper_GFM_Functional_Specification.pdf)

## 3. 영국

### 3.1 GC0137
- NGESO 2019-12 제안, Ofgem 2022-01-31 결정, **2022-02-14 시행**. "비의무 최소사양"으로 GB Grid Forming(구 VSM) 능력을 ECC에 규정. **응답의 종류는 정의하되 최소 크기는 규정하지 않음**. [Ofgem 결정문](https://www.ofgem.gov.uk/sites/default/files/2022-01/GC0137%20Authority%20Decision.pdf) · [NESO](https://www.neso.energy/industry-information/codes/gc/modifications/gc0137-minimum-specification-required-provision-gb-grid-forming-gbgf-capability-formerly-virtual-synchronous-machinevsm-capability)
- 정의 용어: **Active Phase Jump Power**(위상차에 의한 과도 유효전력, <5 ms 자연 응답), **Active ROCOF Response Power**(관성 + 주파수응답), **Active Damping Power**, **Active Control Based Power**. Phase Jump Angle Limit(선형 응답 한계)과 Withstand Limit(전류제한 상태로 안정 유지 최대각) 구분. 현재 특정 위상점프 각은 규정하지 않음. 2026-02-02 위상각 점프 거동 보충 가이던스 발간. [NESO](https://www.neso.energy/document/380216/download) · [NESO 가이던스](https://www.neso.energy/document/362521/download)
- 관련 문서: GB Grid Forming Best Practice Guide(2023), Grid Forming Guidance Note Issue 4(2025). [ESIG 목록](https://www.esig.energy/working-groups/reliability/grid-forming-landscape/specifications-and-interconnection-requirements/)

## 4. EU

### 4.1 RfG 2.0 (Network Code Requirements for Generators 개정)
