# MMC 지식창고 목차

> [!abstract] 범위
> **MMC(Modular Multilevel Converter, 모듈형 멀티레벨 컨버터)** 의 구조·동작 원리·제어·고장·응용·표준을 참고 문서로 정리한다. 계획과 결정 사항은 [[MMC-지식창고-및-강좌-계획]], 배우는 순서대로 읽으려면 [[docs/11-강좌-MMC/00-강좌-목차|MMC 강좌 목차]]를 본다.

> [!info] 작성 규칙
> - 문서 양식은 `templates/문서-템플릿.md`. 수치·연도·사양에는 출처를 붙이고, 없으면 `(확인 필요)`.
> - 모든 전기량은 **pu**. 실물 HVDC 사양(kV, MW)은 응용·사례 문서에서만 단위를 붙여 쓴다.
> - 기존 GFM/GFL 문서와 겹치는 내용은 새로 쓰지 않고 링크한다.

> [!note] 상태
> 아래 문서는 모두 **계획** 상태다. 작성되면 링크가 살아나고, 상태를 `초안 → 검토중 → 확정`으로 올린다.

## 00. 개요
- [[01-MMC란]] — 정의, 암·레그·서브모듈, 한 문단 역사(Marquardt 2001~03, Trans Bay Cable 2010)
- [[02-왜-MMC인가]] — 2레벨 한계, NPC·FC·CHB와 비교, HVDC 표준이 된 이유

## 01. 구조
- [[01-서브모듈-토폴로지]] — HB, FB, 클램프 더블, 하이브리드 암, 상태표
- [[02-암-레그-소자]] — 암 인덕터, SM 커패시터, IGBT·IGCT, 바이패스 스위치, 밸브 타워·냉각

## 02. 동작 원리
- [[01-암-방정식]] — 출력(차동)·순환(공통) 회로 분해, 삽입 지수, 등가 $L_{arm}/2$
- [[02-커패시터-리플-에너지]] — 암 전력과 에너지 맥동, 리플 식, kJ/MVA 설계
- [[03-순환전류]] — 2고조파 음상 성분, 원인과 영향, 의도적 주입

## 03. 변조 · 균형
- [[01-변조기법]] — NLC, PS-PWM, LS-PWM, 레벨 수·고조파·등가 스위칭 주파수
- [[02-전압-균형-알고리즘]] — 정렬, 허용 밴드, 스위칭 저감, 개별 균형 제어기

## 04. 제어
- [[01-제어계층]] — 외부 루프 → 전류 → 순환전류 → 에너지 → 변조·균형 → 게이팅, 직접·보상 변조
- [[02-순환전류-제어]] — CCSC(dq −2ω), 공진 제어기, 불평형 확장
- [[03-에너지-균형-제어]] — 총합·차동, 수평·수직, AC/DC 동역학 분리
- [[04-MMC-GFM]] — HVDC·STATCOM에서의 GFM, 암 에너지와 관성, 요건(GB GC0137 등, 확인 필요)

## 05. 고장 · 보호 · 기동
- [[01-DC-고장]] — HB 차단 불가, FB·하이브리드 차단, DC 차단기, 암 인덕터
- [[02-AC-고장-불평형]] — 음상 제어, 순환전류 성분, 과전류 보호·블로킹
- [[03-기동-정지-SM고장]] — 예비충전, 디블로킹, 중복 SM, 바이패스, 손실 분포
