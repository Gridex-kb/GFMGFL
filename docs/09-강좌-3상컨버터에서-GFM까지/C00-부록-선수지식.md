# C00. 부록 — 선수 지식 요약

> [!abstract] 이 강의에서 답할 질문
> 강좌 전체에서 되풀이해 쓰는 도구 네 가지(복소수 페이저, 임피던스, 라플라스 전달함수, PI 제어기와 대역폭)를 한곳에 모았다. 이 강좌만의 약속인 **진폭 기준 페이저**와 **pu 시간영역 식**도 여기서 정한다.

> [!info] 학습 목표
> - 정현파를 복소수 페이저로 바꾸고, 임피던스로 전류의 크기와 위상을 계산할 수 있다.
> - pu 단위 인덕터 식 $(L/\omega_b)\,di/dt = v - Ri$ 를 읽을 수 있다.
> - 1차 지연의 시정수와 대역폭의 관계를 설명할 수 있다.
> - PI 제어기에서 비례 이득은 대역폭을, 적분 이득은 정상상태 오차 제거를 맡는다는 점을 설명할 수 있다.

## 1. 핵심 개념

### 1.1 복소수와 페이저

오일러 공식(Euler's formula)이 출발점이다.

$$
e^{j\theta} = \cos\theta + j\sin\theta
$$

진폭 $X$, 위상 $\varphi$ 인 정현파는 회전하는 복소수의 실수부로 쓸 수 있다.

$$
x(t) = X\cos(\omega t + \varphi) = \mathrm{Re}\{\bar X e^{j\omega t}\}, \qquad \bar X = X e^{j\varphi} = X\angle\varphi
$$

$\bar X$ 를 **페이저(phasor)** 라 한다. 주파수가 모두 같으면 $e^{j\omega t}$ 는 공통이므로 떼어 내고 $\bar X$ 만 계산한다.

> [!important] 강좌 약속: 페이저 크기는 진폭이다
> 전력공학 교과서는 흔히 실효값(RMS) 페이저를 쓴다. 이 강좌는 1 pu를 **정격 상전압 진폭**으로 잡으므로 페이저 크기도 진폭으로 쓴다. 두 관례는 크기만 $\sqrt2$ 배 다르고 위상은 같다. 자세한 내용은 [[C01-3상-계통의-표현]]에 있다.

복소수 연산은 그대로 위상 연산이 된다.

| 연산 | 의미 |
|---|---|
| $\times e^{j\theta}$ | $\theta$ 만큼 앞으로 회전 |
| $\times j$ | 90° 앞섬 |
| $\div j$ | 90° 뒤짐 |
| 켤레 $\bar X^*$ | 위상 부호 반전 |
| $d/dt$ | $\times j\omega$ |

> [!note]- 유도: 미분이 $j\omega$ 곱이 되는 이유
> $x(t) = \mathrm{Re}\{\bar X e^{j\omega t}\}$ 를 미분한다. $\bar X$ 는 상수이므로
> $$\frac{dx}{dt} = \mathrm{Re}\{\bar X \cdot j\omega\, e^{j\omega t}\} = \mathrm{Re}\{(j\omega \bar X) e^{j\omega t}\}$$
> 즉 미분 신호의 페이저는 $j\omega\bar X$ 다. 크기는 $\omega$ 배, 위상은 90° 앞선다. 적분은 반대로 $\bar X/(j\omega)$ 다.

### 1.2 임피던스 (pu)

페이저로 쓰면 미분방정식이 대수식이 된다.

$$
\bar V = Z\,\bar I, \qquad Z = R + jX
$$

- 인덕터: $X_L = \omega L$. 전류가 전압보다 90° 뒤진다.
- 커패시터: $X_C = -1/(\omega C)$. 전류가 90° 앞선다. 서셉턴스 $B = \omega C$ 로 쓰기도 한다.

pu에서는 각주파수도 기준값 $\omega_b = 2\pi\cdot 60$ rad/s 로 나눈 $\omega_{pu}$ 를 쓴다. 그러면 $X = \omega_{pu} L$ 이고, 정격 주파수($\omega_{pu}=1$)에서 **리액턴스와 인덕턴스가 같은 숫자**가 된다. "$L_f$ = 0.2 pu"는 60 Hz에서 리액턴스 0.2 pu라는 뜻이다.

시간영역 식은 $\omega_b$ 가 앞에 붙는다.

$$
\frac{L}{\omega_b}\frac{di}{dt} = v - R\,i, \qquad \frac{C}{\omega_b}\frac{dv}{dt} = i
$$

강좌의 시뮬레이터 `simulation/emt/gfm_gfl_emt.py` 도 이 형태(`di = (v - R*i) * wb / L`)로 적분한다.

> [!note]- 유도: pu 인덕터 식에 $\omega_b$ 가 붙는 이유
> 기준값을 $V_b, I_b$ 로 두면 $Z_b = V_b/I_b$ 이고, 인덕턴스 기준은 "정격 주파수에서 리액턴스가 $Z_b$ 인 인덕턴스", 즉 $L_b = Z_b/\omega_b$ 다.
> 물리 식 $v = L\,di/dt$ 에 $v = v_{pu}V_b$, $i = i_{pu}I_b$, $L = L_{pu}L_b$ 를 넣는다.
> $$v_{pu}V_b = L_{pu}\frac{Z_b}{\omega_b} I_b \frac{di_{pu}}{dt} \;\Rightarrow\; v_{pu} = \frac{L_{pu}}{\omega_b}\frac{di_{pu}}{dt}$$
> 시간은 초 그대로 두었으므로 $1/\omega_b$ 가 남는다. 커패시터도 $C_b = 1/(Z_b\omega_b)$ 로 같은 결과를 얻는다.

### 1.3 라플라스 변환 최소 요약

라플라스 변환(Laplace transform)은 미분방정식을 $s$ 의 대수식으로 바꾼다. 실전에서는 아래 표 정도면 충분하다.

| 시간영역 | $s$ 영역 | 비고 |
|---|---|---|
| $dx/dt$ | $sX(s)$ | 초기값 0 |
| $\int x\,dt$ | $X(s)/s$ | |
| 계단(크기 1) | $1/s$ | |
| 시간 지연 $T_d$ | $e^{-sT_d}$ | 디지털 제어 지연 ([[C06-디지털-제어와-지연]]) |
| $1 - e^{-t/\tau}$ | $\dfrac{1}{s(1+s\tau)}$ | 1차 지연의 계단응답 |

- **전달함수(transfer function)** $G(s) = Y(s)/X(s)$. 예: pu R-L 회로의 전류/전압은 $1/(R + sL/\omega_b)$.
- **정현파 정상상태 응답**은 $s = j\omega$ 를 넣어 얻는다. 크기 $|G(j\omega)|$, 위상 $\angle G(j\omega)$. 페이저 계산과 같은 이야기다.
- **안정도**: 분모가 0이 되는 $s$(극점, pole)가 모두 복소평면 왼쪽에 있으면 안정하다.
- **최종값 정리**: $y(\infty) = \lim_{s\to 0} sY(s)$. 정상상태 오차를 볼 때 쓴다.

### 1.4 1차 지연

$$
G(s) = \frac{1}{1 + s\tau}
$$

- 계단응답은 $1 - e^{-t/\tau}$ 다. $t=\tau$ 에서 63.2 %, $3\tau$ 에서 95 % 에 이른다.
- **대역폭(bandwidth)** $f_c = 1/(2\pi\tau)$. 이 주파수에서 크기가 −3 dB(0.707배), 위상이 −45° 다.
- 상승시간(10 → 90 %)은 약 $2.2\tau = 0.35/f_c$ 다.

강좌에서 1차 지연은 여러 곳에 나온다. R-L 회로($\tau = L/(\omega_b R)$), 측정 저역통과필터(LPF), 디지털 제어 지연의 근사(평균값 모델의 `t_delay` 150 µs), 그리고 잘 설계한 전류 제어 폐루프다.

> [!note]- 유도: 계단응답과 −3 dB 주파수
> 입력 $1/s$ 에 대한 출력은 부분분수로 나눈다.
> $$Y(s) = \frac{1}{s(1+s\tau)} = \frac{1}{s} - \frac{1}{s + 1/\tau} \;\Rightarrow\; y(t) = 1 - e^{-t/\tau}$$
> 주파수 응답은 $|G(j\omega)| = 1/\sqrt{1 + (\omega\tau)^2}$ 다. $\omega\tau = 1$ 이면 $1/\sqrt2$ (−3 dB)이고 $\angle G = -\arctan 1 = -45°$ 다. 따라서 $\omega_c = 1/\tau$, $f_c = 1/(2\pi\tau)$.

### 1.5 PI 제어기와 대역폭

$$
C(s) = K_p + \frac{K_i}{s}
$$

- **비례항**은 오차에 즉시 반응한다. 응답 속도, 즉 대역폭을 정한다.
- **적분항**은 오차가 남아 있는 한 출력을 계속 쌓는다. 그래서 **직류 지령**에 대한 정상상태 오차가 0이 된다.
- 교류 지령에는 적분항만으로 오차가 사라지지 않는다. 그래서 3상 제어는 정현파를 직류로 바꾸는 dq 좌표에서 PI를 쓴다([[C02-공간벡터-좌표변환-pu]]).

**대역폭**은 폐루프 응답이 −3 dB 로 떨어지는 주파수다. "얼마나 빠른 변화까지 따라가는가"를 한 숫자로 나타낸다.

가장 단순한 설계는 R-L 플랜트 $1/(R + sL/\omega_b)$ 의 극점을 PI의 영점으로 지우는 것이다.

$$
K_p = \frac{\omega_c L}{\omega_b}, \qquad K_i = K_p\,\frac{R\,\omega_b}{L} \quad\Rightarrow\quad \frac{I(s)}{I^*(s)} = \frac{1}{1 + s/\omega_c}
$$

폐루프가 대역폭 $\omega_c$ 인 1차 지연이 된다. 시뮬레이터도 $K_p = \omega_{cc}L_f/\omega_b$ (전류 제어 대역폭 800 Hz)를 쓴다. 적분 이득은 외란 억제를 위해 다르게 잡는데, 그 이유는 [[C07-전류-제어]]에서 다룬다.

> [!note]- 유도: 극점 상쇄로 폐루프가 1차가 되는 과정
> 개루프 전달함수를 정리한다.
> $$C(s)P(s) = K_p\frac{s + K_i/K_p}{s}\cdot\frac{\omega_b/L}{s + R\omega_b/L}$$
> $K_i/K_p = R\omega_b/L$ 로 고르면 분자·분모의 $(s + R\omega_b/L)$ 가 지워진다.
> $$C(s)P(s) = \frac{K_p\,\omega_b}{L\,s} = \frac{\omega_c}{s}$$
> 단위 되먹임 폐루프는 $T(s) = \dfrac{\omega_c/s}{1 + \omega_c/s} = \dfrac{1}{1 + s/\omega_c}$ 다.

> [!tip] 대역폭에 관한 두 가지 경험칙
> - **루프 분리**: 바깥 루프는 안쪽 루프보다 5~10배 느리게 잡는다. 그래야 바깥 루프가 안쪽 루프를 "이상적인 1"로 볼 수 있다. 예: 전류 제어 800 Hz, PLL 고유주파수 20 Hz, 전력 측정 LPF 20 Hz.
> - **상한**: 디지털 제어의 지연(약 150 µs) 때문에 대역폭을 끝없이 올릴 수 없다. 보통 스위칭 주파수의 1/10 안팎이 한계다([[C06-디지털-제어와-지연]]).

## 3. Python 실습

numpy만으로 페이저 계산과 PI 전류 제어의 계단응답을 확인한다.

```python
# 저장소 루트에서 실행 (numpy만 사용)
import numpy as np

wb = 2 * np.pi * 60            # 기준 각주파수 [rad/s]

# 1) 페이저: 1 pu 전압을 R-L 직렬 임피던스에 걸면?
R, L = 0.005, 0.2              # pu (컨버터측 필터 Lf 수준)
Z = R + 1j * L                 # 정격 주파수에서 X = ω·L = L (pu)
V = 1.0 + 0j                   # 1∠0° (진폭 기준 페이저)
I = V / Z
print(f"|I| = {abs(I):.2f} pu, 위상 = {np.degrees(np.angle(I)):.1f}°")

# 2) 같은 R-L에 PI 전류 제어기를 붙이면 1차 지연이 된다 (오일러 적분)
f_c = 800.0                    # 원하는 폐루프 대역폭 [Hz]
w_c = 2 * np.pi * f_c
Kp = w_c * L / wb              # 비례 이득: 대역폭을 정한다
Ki = Kp * R * wb / L           # 적분 이득: 플랜트 극점을 상쇄 (내부모델 설계)
dt, T = 1e-6, 2e-3
i, integ, i_ref = 0.0, 0.0, 1.0
t = np.arange(0, T, dt)
y = np.empty_like(t)
for k in range(len(t)):
    e = i_ref - i
    integ += Ki * e * dt
    v = Kp * e + integ         # 제어기 출력 전압 [pu]
    i += (v - R * i) * wb / L * dt   # (L/ωb)·di/dt = v − R·i
    y[k] = i

tau = 1 / w_c
print(f"τ = 1/ω_c = {tau*1e3:.3f} ms, t=τ 에서 응답 = {np.interp(tau, t, y):.3f} (이론 0.632)")
t10, t90 = np.interp([0.1, 0.9], y, t)
print(f"상승시간(10→90 %) = {(t90-t10)*1e3:.3f} ms, 0.35/f_c = {0.35/f_c*1e3:.3f} ms")
print(f"참고: PI 없이 R-L 자체 시정수 L/(ωb·R) = {L/(wb*R):.3f} s")
```

실행 결과:

```text
|I| = 5.00 pu, 위상 = -88.6°
τ = 1/ω_c = 0.199 ms, t=τ 에서 응답 = 0.635 (이론 0.632)
상승시간(10→90 %) = 0.436 ms, 0.35/f_c = 0.437 ms
참고: PI 없이 R-L 자체 시정수 L/(ωb·R) = 0.106 s
```

필터 인덕터 하나에 1 pu 전압 차가 걸리면 전류가 5 pu가 된다. 컨버터가 전압을 정밀하게 맞춰야 하는 이유다. R-L 자체의 시정수는 0.1 s 로 느리지만, PI 제어기가 이를 0.2 ms 짜리 1차 지연으로 바꾼다.

> [!tip] 해볼 것
> - `f_c` 를 200 Hz, 2000 Hz로 바꿔 상승시간이 $0.35/f_c$ 를 따르는지 확인한다.
> - `Ki = 0` 으로 두고 `R = 0.5` 로 키워 본다. 정상상태 값이 $K_p/(K_p + R)$ 에 머무는 것, 즉 적분항이 없으면 오차가 남는 것을 확인한다.

## 4. 흔한 오해

> [!warning] 오해: 페이저 크기는 언제나 실효값이다
> 관례일 뿐이다. 이 강좌는 1 pu = 정격 상전압 진폭이므로 페이저 크기도 진폭으로 쓴다. 섞어 쓰지만 않으면 위상과 pu 비율은 그대로다.

> [!warning] 오해: 대역폭은 높을수록 좋다
> 대역폭을 올리면 잡음과 고조파도 더 잘 따라가고, 지연과 결합해 위상 여유가 줄어든다. 약계통에서는 빠른 루프가 계통과 상호작용해 진동을 만들기도 한다([[C10-약계통과-제어-상호작용]]). 루프마다 맡은 시간대를 나눠 대역폭을 정한다.

> [!warning] 오해: pu에서도 리액턴스와 인덕턴스는 다른 숫자다
> 정격 주파수에서는 같은 숫자다($X = \omega_{pu}L$, $\omega_{pu}=1$). 주파수가 바뀔 때만 구별하면 된다.

## 5. 확인 문제

1. $Z = 0.8 + j0.6$ pu 에 1∠0° pu 전압을 걸었다. 전류 페이저는? 60 Hz에서 전류는 전압보다 몇 ms 뒤지는가?

> [!success]- 답
> $|Z| = 1$, $\angle Z = 36.9°$ 이므로 $\bar I = 1\angle{-36.9°}$ pu. 한 주기 16.67 ms 중 36.9/360 만큼이므로 약 1.71 ms 뒤진다.

2. 시정수 $\tau$ = 2 ms 인 1차 지연의 대역폭은? 계단 입력 후 6 ms 에서 출력은 최종값의 몇 % 인가?

> [!success]- 답
> $f_c = 1/(2\pi\cdot 0.002) \approx 79.6$ Hz. 6 ms $= 3\tau$ 이므로 $1 - e^{-3} \approx 95$ %.

3. $L$ = 0.2 pu, $R$ = 0.005 pu 플랜트에 폐루프 대역폭 500 Hz 인 PI 제어기를 극점 상쇄로 설계하라. $K_p$, $K_i$ 는?

> [!success]- 답
> $K_p = \omega_c L/\omega_b = (2\pi\cdot 500)(0.2)/(2\pi\cdot 60) \approx 1.667$.
> $K_i = K_p R\omega_b/L = 1.667 \times 0.005 \times 377/0.2 \approx 15.7$ pu/s.
> $\omega_b$ 가 약분되어 $K_p = (f_c/60)\,L$ 로도 계산할 수 있다.
