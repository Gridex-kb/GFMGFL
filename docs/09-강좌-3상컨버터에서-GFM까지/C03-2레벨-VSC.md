# C03. 2레벨 전압형 컨버터 (VSC)

> [!abstract] 이 강의에서 답할 질문
> 스위치 6개가 켜고 끄는 것만으로 3상 교류 전압이 어떻게 생기는가? 스위치는 한순간에 정확히 8가지 상태 중 하나만 만들 수 있고, 그 상태들이 αβ 평면에 그리는 육각형이 컨버터가 낼 수 있는 전압의 전부다.

> [!info] 학습 목표
> - 레그(leg)당 상·하 스위치의 상보 동작과 극전압 ±V_dc/2 (= ±1.128 pu)를 설명할 수 있다.
> - 극전압에서 영상분을 빼서 상전압을 구하고, 영상분이 공간벡터에 나타나지 않는 이유를 말할 수 있다.
> - 스위칭 상태 8개(유효 6 + 영 2)의 αβ 벡터를 계산하고, 육각형(꼭짓점 크기 2/3·V_dc = 1.504 pu)을 그릴 수 있다.
> - DC 링크(DC link)가 무엇을 하는지, 이 강좌의 모델에서는 어떻게 단순화했는지 설명할 수 있다.

## 1. 핵심 개념

### 1.1 구조: 레그 3개, 스위치 6개

2레벨 전압형 컨버터(two-level voltage source converter, VSC)는 DC 링크 양단(P, N) 사이에 **레그 3개**를 병렬로 둔다. 각 레그는 상단 스위치와 하단 스위치 두 개로 되어 있고, 두 스위치 사이의 중점이 교류 출력 단자 a, b, c가 된다. 스위치에는 역병렬 다이오드가 붙어 있어 전류는 양방향으로 흐를 수 있다.

- **상보 동작(complementary switching)**: 한 레그의 상·하 스위치는 항상 반대로 동작한다. 둘 다 켜면 DC 링크가 단락(shoot-through)되고, 둘 다 끄면 출력 전압이 전류 방향에 따라 정해져 제어할 수 없다.
- 그래서 레그 하나는 **스위칭 함수(switching function)** $S_x \in \{0, 1\}$ 하나로 완전히 표현된다. $S_x = 1$ 은 상단 ON(출력이 P에 연결), $S_x = 0$ 은 하단 ON(출력이 N에 연결).

> [!note] 데드타임 (개념만)
> 실제 구동에서는 단락을 막기 위해 상·하 스위치를 모두 끄는 짧은 데드타임(dead time)을 둔다. 이 시간 동안 출력 전압은 전류 방향이 정하므로 작은 전압 오차가 생긴다. 이 강좌의 모델은 데드타임을 넣지 않는다.

### 1.2 극전압: ±V_dc/2

DC 링크 중점(가상의 점 0)을 기준으로 잰 출력 단자 전압을 **극전압(pole voltage)** 이라 한다. 스위치가 둘 중 하나의 상태만 가지므로 극전압도 두 값뿐이다. 그래서 "2레벨"이다.

$$
v_{x0} = (2S_x - 1)\,\frac{V_{dc}}{2} = \pm\,1.128\ \text{pu}, \qquad x \in \{a, b, c\}
$$

이 강좌의 기준 설비는 $V_{dc} = 2.256$ pu (1 pu = 정격 상전압 진폭)다. 선간전압 $v_{ab} = v_{a0} - v_{b0}$ 은 $\{-V_{dc},\ 0,\ +V_{dc}\}$ 세 값을 가진다.

### 1.3 상전압: 극전압에서 영상분을 뺀다

부하(또는 계통 측 변압기)가 중성점을 DC 링크와 연결하지 않은 평형 3선식이면, 부하 중성점 n 의 전위는 극전압의 평균이 된다. 이것이 **영상분(zero-sequence, 공통모드 common-mode)** 전압이다.

$$
v_{n0} = \frac{v_{a0} + v_{b0} + v_{c0}}{3}, \qquad v_{xn} = v_{x0} - v_{n0}
$$

> [!note]- 유도: 부하 중성점 전위가 극전압 평균이 되는 이유
> 각 상 부하 임피던스가 같고($Z$), 중성선이 없으면 $i_a + i_b + i_c = 0$ 이다.
> 각 상에서 $v_{x0} = Z\,i_x + v_{n0}$ 이므로 세 식을 더하면
> $$
> v_{a0} + v_{b0} + v_{c0} = Z\,(i_a + i_b + i_c) + 3\,v_{n0} = 3\,v_{n0}.
> $$
> 따라서 $v_{n0} = (v_{a0}+v_{b0}+v_{c0})/3$, 상전압 $v_{xn} = v_{x0} - v_{n0}$ 이고 $v_{an}+v_{bn}+v_{cn} = 0$ 이다.
> 같은 결론이 인덕터·커패시터를 포함한 평형 부하에도 성립한다(각 상 방정식이 같은 연산자 $Z(s)$ 를 가지므로).

상전압은 $\{0,\ \pm V_{dc}/3,\ \pm 2V_{dc}/3\} = \{0,\ \pm 0.752,\ \pm 1.504\}$ pu 다섯 값만 가진다. 영상분은 3상 모두에 똑같이 들어가므로 선간전압과 상전류를 바꾸지 못한다. 그래서 컨버터는 영상분을 **자유롭게 쓸 수 있는 여분의 자유도**로 쓴다. 이 자유도가 [[C04-변조-SPWM-SVPWM]]의 영상분 주입이다.

### 1.4 스위칭 상태 8개와 전압 벡터 육각형

레그 3개가 각각 2상태이므로 상태는 $2^3 = 8$ 개다. 진폭 불변 변환([[C02-공간벡터-좌표변환-pu]])으로 각 상태의 공간벡터를 구하면:

$$
\vec v = \frac{2}{3}\left(v_{a0} + a\,v_{b0} + a^2 v_{c0}\right) = \frac{2}{3}V_{dc}\left(S_a + a\,S_b + a^2 S_c\right), \qquad a = e^{j2\pi/3}
$$

- **유효 벡터(active vector) 6개**: 크기 $\tfrac{2}{3}V_{dc} = 1.504$ pu, 각도 0°, 60°, …, 300°. 꼭짓점을 이으면 정육각형이다.
- **영벡터(zero vector) 2개**: (000)과 (111). 모든 단자가 같은 레일에 붙어 선간전압이 0이다.

| 상태 $(S_aS_bS_c)$ | 벡터 | 각도 | 영상분 $v_{n0}$ [pu] |
|---|---|---|---|
| 100 | V1 | 0° | −0.376 |
| 110 | V2 | 60° | +0.376 |
| 010 | V3 | 120° | −0.376 |
| 011 | V4 | 180° | +0.376 |
| 001 | V5 | 240° | −0.376 |
| 101 | V6 | 300° | +0.376 |
| 000 / 111 | V0 / V7 | — | −1.128 / +1.128 |

> [!note]- 유도: 극전압의 공통 오프셋이 공간벡터에서 사라지는 이유와 벡터 크기
> $1 + a + a^2 = 0$ 이므로, 세 상에 똑같이 더해진 값 $k$ 는 $\tfrac{2}{3}(k + a k + a^2 k) = 0$ 이 된다.
> 극전압 $v_{x0} = S_x V_{dc} - V_{dc}/2$ 의 $-V_{dc}/2$ 항과 영상분 $v_{n0}$ 모두 이런 공통값이다. 따라서
> $$
> \vec v = \tfrac{2}{3}(v_{a0} + a v_{b0} + a^2 v_{c0}) = \tfrac{2}{3}(v_{an} + a v_{bn} + a^2 v_{cn}) = \tfrac{2}{3}V_{dc}(S_a + a S_b + a^2 S_c).
> $$
> 예) 100: $\tfrac{2}{3}V_{dc}\cdot 1 = 1.504$ pu ∠0°.
> 110: $\tfrac{2}{3}V_{dc}(1 + a) = \tfrac{2}{3}V_{dc}(-a^2) = \tfrac{2}{3}V_{dc}\,e^{j\pi/3}$ → 1.504 pu ∠60°.
> 모델 `Inverter.pwm()` 은 극전압을 그대로 넣어 $\tfrac{2}{3}(s_a + s_b e^{j2\pi/3} + s_c e^{-j2\pi/3})$ 를 계산하는데, 위 성질 때문에 영상분을 따로 빼지 않아도 된다.

### 1.5 순시값은 8개뿐, 평균은 육각형 안 어디든

어느 순간이든 컨버터 출력은 위 8개 벡터 중 하나다. 그러나 한 스위칭 주기(5 kHz → 200 µs) 안에서 인접한 유효 벡터 두 개와 영벡터를 시간 비율로 섞으면, **주기 평균**으로는 육각형 내부의 어떤 벡터든 만들 수 있다(전압-시간 면적 평형). 회전하는 원형 전압 벡터를 왜곡 없이 내려면 원이 육각형 안에 들어가야 하므로, 선형 영역의 최대 상전압 진폭은 내접원 반지름이다.

$$
\hat V_{\max} = \frac{V_{dc}}{\sqrt 3} \approx 1.302\ \text{pu}
$$

> [!note]- 유도: 내접원 반지름
> 정육각형의 꼭짓점 거리가 $R = \tfrac{2}{3}V_{dc}$ 일 때, 중심에서 변까지 거리는 $R\cos 30° = \tfrac{2}{3}V_{dc}\cdot\tfrac{\sqrt3}{2} = V_{dc}/\sqrt3$.
> $V_{dc} = 2.256$ pu 를 넣으면 $1.3026$ pu (이 강좌에서는 1.302 pu로 표기).

어떤 순서와 비율로 섞는지가 변조(modulation)이고, [[C04-변조-SPWM-SVPWM]]에서 다룬다. 육각형 꼭짓점을 60°씩 그대로 돌아가는 극단적 경우(6스텝, six-step)는 그림 2에서 극전압·상전압의 관계를 보기 위해 쓴다.

### 1.6 DC 링크의 역할

- **전압원**: 레그들이 공유하는 단단한(stiff) 전압 $V_{dc}$ 를 제공한다. 위에서 본 모든 전압 크기가 $V_{dc}$ 에 비례하므로, $V_{dc}$ 가 컨버터가 낼 수 있는 교류 전압의 상한을 정한다.
- **에너지 완충**: 무손실이면 순시 전력은 같다($p_{dc} = p_{ac}$). 평형 3상에서 교류측 순시 전력은 거의 일정하므로 DC 링크 커패시터는 주로 스위칭 주파수 리플 전류만 흡수한다.
- **이 강좌의 단순화**: 모델(`simulation/emt/gfm_gfl_emt.py`)은 DC 링크를 이상적 직류원($V_{dc}$ = 2.256 pu 일정)으로 둔다. DC 전압 제어와 1차 전원의 한계는 다루지 않는다.

> [!info] 3레벨로 가면
> 레그마다 DC 중점에 연결되는 상태를 하나 더 두면 극전압이 +V_dc/2, 0, −V_dc/2 세 값이 되고 상태는 27개가 된다. → [[C03B-3레벨-컨버터]] (선택 강의)

## 3. Python 실습

**실습 1 — 8개 상태 표 만들기.** 극전압, 영상분, 상전압, 공간벡터를 계산하고 "영상분은 αβ에 나타나지 않는다"를 `assert` 로 확인한다.

```python
# 저장소 루트에서 실행
import itertools
import numpy as np

V_dc = 2.256                          # DC 링크 [pu]
a = np.exp(2j * np.pi / 3)

print("상태  극전압(a,b,c)            영상분   상전압 a    |V|     각도")
for s in itertools.product((1, 0), repeat=3):
    v_pole = (2 * np.array(s) - 1) * V_dc / 2          # 1 → +V_dc/2, 0 → -V_dc/2
    v_n0 = v_pole.mean()                                # 영상분 (부하 중성점 전위)
    v_ph = v_pole - v_n0                                # 상전압
    v_ab = (2 / 3) * (v_pole[0] + a * v_pole[1] + a**2 * v_pole[2])
    v_ab2 = (2 / 3) * (v_ph[0] + a * v_ph[1] + a**2 * v_ph[2])
    assert abs(v_ab - v_ab2) < 1e-12                    # 영상분은 αβ에 나타나지 않는다
    ang = round(np.degrees(np.angle(v_ab)), 1) + 0.0 if abs(v_ab) > 1e-9 else 0.0
    print(f"{''.join(map(str, s))}   {np.round(v_pole, 3)}  {v_n0:+.3f}   {v_ph[0]:+.3f}   "
          f"{abs(v_ab):.3f}  {ang:6.1f}°")
```

출력 예(일부):

```
110   [ 1.128  1.128 -1.128]  +0.376   +0.752   1.504    60.0°
100   [ 1.128 -1.128 -1.128]  -0.376   +1.504   1.504     0.0°
000   [-1.128 -1.128 -1.128]  -1.128   +0.000   0.000     0.0°
```

**실습 2 — 모델의 PWM이 만드는 벡터 확인.** 모델의 `Inverter.pwm(t)` 는 상별 듀티(−1~1)를 삼각파 반송파(−1~1, t = 0 에서 골)와 비교해 스위치 상태를 정하고, 그 상태의 αβ 전압을 `vpole` 에 넣는다.

```python
# 저장소 루트에서 실행
import sys; sys.path.insert(0, "simulation/emt")
from gfm_gfl_emt import Params, Scenario, Inverter

inv = Inverter("GFM", Params(), Scenario())
print(f"V_dc = {inv.vdc:.3f} pu")
inv.duty = (0.5, -0.2, -0.3)          # 상별 듀티 [-1, 1] (보통은 sample()이 계산)
for t in (0.0, 50e-6, 100e-6):        # 반송파: 0 µs 골(-1), 50 µs 0, 100 µs 꼭짓점(+1)
    inv.pwm(t)
    print(f"t = {t*1e6:5.1f} µs  v_pole(αβ) = {inv.vpole.real:+.3f} {inv.vpole.imag:+.3f}j  |v| = {abs(inv.vpole):.3f} pu")
```

```
V_dc = 2.256 pu
t =   0.0 µs  v_pole(αβ) = +0.000 +0.000j  |v| = 0.000 pu     ← (111) 영벡터
t =  50.0 µs  v_pole(αβ) = +1.504 +0.000j  |v| = 1.504 pu     ← (100) V1
t = 100.0 µs  v_pole(αβ) = -0.000 +0.000j  |v| = 0.000 pu     ← (000) 영벡터
```

> [!tip] 해볼 것
> - 실습 2에서 듀티를 `(0.5, 0.3, -0.3)` 으로 바꾸고 t = 0~100 µs 를 10 µs 간격으로 훑어 보라. 어떤 순서로 (111) → (110) → (100) → (000) 이 나오는가? 한 반송파 반주기 안에 영벡터가 양 끝에 오는 것이 [[C04-변조-SPWM-SVPWM]]의 대칭 배치다.
> - 실습 1에 선간전압 `v_pole[0] - v_pole[1]` 을 추가해 {−2.256, 0, +2.256} 세 값만 나오는지 확인하라.

## 4. 흔한 오해

> [!warning] 오해: 인버터는 사인파 전압을 출력한다
> 실제 컨버터 단자 전압은 매 순간 8개 벡터 중 하나, 상전압으로는 다섯 값의 계단이다. "사인파"는 스위칭 주기 평균이고, 전류가 매끄러운 것은 필터 인덕터가 고주파 성분을 걸러 주기 때문이다([[C05-필터-변압기-측정점]]). 기준 설비($L_f$ = 0.2 pu, 5 kHz)에서도 컨버터측 전류에는 약 0.11 pu (피크-피크) 리플이 남는다.

> [!warning] 오해: 극전압과 상전압은 같은 것이다
> 극전압은 DC 중점 기준, 상전압은 부하 중성점 기준이다. 둘은 영상분 $v_{n0}$ 만큼 다르다. 영상분은 3상 공통이라 전류를 만들지 않지만, 변압기 중성점 접지나 기생 커패시턴스가 있으면 공통모드 전류의 원인이 된다.

> [!warning] 오해: 영벡터는 하나만 있으면 된다
> (000)과 (111)은 αβ 벡터는 같지만 영상분이 −1.128 pu 와 +1.128 pu 로 반대다. 어느 쪽을 얼마나 쓰느냐가 영상분 파형과 스위칭 횟수를 정한다. 두 영벡터를 같은 시간씩 나눠 쓰는 것이 SVPWM이고, 이것이 min-max 영상분 주입과 같다.

## 5. 확인 문제

1. 상태 (110)에서 극전압, 영상분, a·b·c 상전압, 공간벡터의 크기와 각도를 구하라.

> [!success]- 답
> 극전압 $(+1.128, +1.128, -1.128)$ pu, 영상분 $v_{n0} = +0.376$ pu.
> 상전압 $(+0.752, +0.752, -1.504)$ pu (합 0).
> 공간벡터 $\tfrac{2}{3}V_{dc}(1 + a) = 1.504$ pu ∠60° (V2).

2. $V_{dc}$ 는 2.256 pu 인데 유효 벡터의 크기는 1.504 pu, 왜곡 없이 낼 수 있는 상전압 진폭은 1.302 pu 다. 세 숫자의 관계를 설명하라.

> [!success]- 답
> 극전압은 ±$V_{dc}/2$ 로 흔들리지만, 3상 공간벡터로 묶으면 크기 $\tfrac{2}{3}V_{dc}$ = 1.504 pu 의 꼭짓점 6개가 된다. 평균 벡터는 그 육각형 안에서만 만들 수 있으므로, 일정한 크기로 회전하는 벡터의 최대 크기는 내접원 반지름 $V_{dc}/\sqrt3$ = 1.302 pu 다. 즉 1.302 pu 는 선간전압 진폭이 $V_{dc}$ 와 같아지는 지점이다($\sqrt3 \times 1.302 = 2.256$).

3. 모델 `Inverter.pwm()` 은 극전압 $\pm V_{dc}/2$ 를 그대로 Clarke 변환에 넣는다. 영상분을 빼지 않아도 상전압 기준 결과와 같은 이유는?

> [!success]- 답
> $1 + a + a^2 = 0$ 이므로 세 상에 공통으로 더해진 성분(극전압의 $-V_{dc}/2$ 오프셋과 영상분 $v_{n0}$)은 진폭 불변 변환에서 정확히 0이 된다. αβ 성분만으로 계산하는 필터·전류 동특성에는 영상분이 영향을 주지 않는다.
