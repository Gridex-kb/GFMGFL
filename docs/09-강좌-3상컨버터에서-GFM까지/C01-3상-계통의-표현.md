# C01. 3상 계통의 표현

> [!abstract] 이 강의에서 답할 질문
> 3상 전압과 전류는 어떻게 적고 읽는가? 한 상의 전력은 120 Hz로 맥동하는데, 왜 세 상을 더하면 일정해지는가?

> [!info] 학습 목표
> - 평형 3상과 상순을 정의하고, 상전압에서 선간전압의 크기($\sqrt3$ 배)와 위상(30° 앞섬)을 구할 수 있다.
> - 진폭과 실효값을 pu로 바꿔 쓸 수 있다.
> - 3상 순시전력이 일정해지는 이유를 설명하고, 유효전력과 무효전력을 pu로 계산할 수 있다.

## 1. 핵심 개념

### 1.1 평형 3상과 상순

$$
v_a = V\cos(\omega t), \quad v_b = V\cos(\omega t - 120°), \quad v_c = V\cos(\omega t + 120°)
$$

- **평형(balanced)**: 세 상의 진폭이 같고 위상이 120° 씩 떨어져 있다. 이때 순시값의 합은 언제나 0이다.
- **상순(phase sequence)**: a → b → c 순서로 최대값에 이르면 **정상분(positive sequence)** 이다. 두 상을 바꾸면 **역상분(negative sequence)** 이 되어 전동기가 반대로 돈다.
- 페이저로 쓰면 $\bar V_a = V\angle 0°$, $\bar V_b = V\angle{-120°}$, $\bar V_c = V\angle 120°$ 다.

회전 연산자 $a = e^{j120°}$ 를 쓰면 $\bar V_b = a^2\bar V_a$, $\bar V_c = a\bar V_a$ 다. 이 $a$ 는 [[C02-공간벡터-좌표변환-pu]]의 Clarke 변환에 다시 나온다.

> [!note]- 유도: 평형 3상의 합이 0인 이유
> 세 페이저의 합은 $\bar V_a(1 + a^2 + a)$ 다.
> $$1 + a + a^2 = 1 + \left(-\tfrac12 + j\tfrac{\sqrt3}{2}\right) + \left(-\tfrac12 - j\tfrac{\sqrt3}{2}\right) = 0$$
> 페이저 합이 0이므로 순시값 합 $v_a + v_b + v_c = \mathrm{Re}\{(\bar V_a + \bar V_b + \bar V_c)e^{j\omega t}\}$ 도 0이다.

### 1.2 상전압과 선간전압

- **상전압(phase voltage)**: 중성점 기준 전압. $v_a, v_b, v_c$.
- **선간전압(line-to-line voltage)**: 두 상 사이 전압. $v_{ab} = v_a - v_b$.

$$
\bar V_{ab} = \sqrt3\,\bar V_a\,e^{j30°}
$$

선간전압은 상전압보다 **크기가 $\sqrt3$ 배, 위상이 30° 앞선다**. 상전압 진폭이 1 pu이면 선간전압 진폭은 $\sqrt3 \approx 1.732$ pu다.

중성선이 없는 3선식 컨버터와 Δ 결선 변압기에서는 선간전압만 의미를 가진다. 컨버터의 극전압과 상전압의 관계는 [[C03-2레벨-VSC]]에서 다룬다.

> [!note]- 유도: $\sqrt3$ 과 30°
> $\bar V_a = V\angle 0°$ 로 두면
> $$\bar V_{ab} = V\left(1 - e^{-j120°}\right) = V\left(1 + \tfrac12 + j\tfrac{\sqrt3}{2}\right) = V\left(\tfrac32 + j\tfrac{\sqrt3}{2}\right)$$
> 크기는 $V\sqrt{9/4 + 3/4} = \sqrt3\,V$, 각도는 $\arctan\!\big((\sqrt3/2)/(3/2)\big) = \arctan(1/\sqrt3) = 30°$ 다.

### 1.3 진폭과 실효값

**실효값(RMS)** 은 같은 저항에서 같은 평균 전력을 내는 직류 값이다. 정현파의 실효값은 진폭의 $1/\sqrt2$ 다.

| 양 | 값 [pu] |
|---|---|
| 상전압 진폭 | 1 |
| 상전압 실효값 | $1/\sqrt2 \approx 0.707$ |
| 선간전압 진폭 | $\sqrt3 \approx 1.732$ |
| 선간전압 실효값 | $\sqrt{3/2} \approx 1.225$ |

명판의 "정격 전압"은 관례상 **선간 실효값**이다. 설비가 명판 정격 전압으로 운전 중이면, 이 강좌 기준으로는 상전압 진폭이 1 pu다. 둘은 같은 운전점을 다른 양으로 적은 것이다.

> [!tip] pu 비율은 기준만 일관되면 같다
> 계통코드의 "0.9 pu 이하에서 FRT 진입" 같은 값은 비율이다. 진폭 기준이든 실효값 기준이든, 전압과 기준을 같은 종류로 재면 같은 숫자가 나온다. 문제는 진폭 측정값을 실효값 기준으로 나누는 식으로 **섞을 때**만 생긴다.

### 1.4 3상 순시전력: 맥동이 상쇄된다

상전류를 $i_k = I\cos(\omega t - 120°k - \varphi)$ 로 두자($k$ = 0, 1, 2 가 a, b, c; $\varphi$ 는 전압 대비 전류의 뒤짐각). 한 상의 순시전력은 평균값 위에 **2배 주파수(120 Hz) 맥동**이 얹힌다.

$$
p_a(t) = v_a i_a = \frac{VI}{2}\left[\cos\varphi + \cos(2\omega t - \varphi)\right]
$$

그런데 세 상을 더하면 맥동이 사라진다.

$$
p(t) = v_a i_a + v_b i_b + v_c i_c = \frac32\,V I\cos\varphi \quad (\text{일정})
$$

이유는 간단하다. 세 상의 120 Hz 맥동은 서로 240° 씩 어긋난 정현파다. 240° 는 −120° 와 같으므로, 평형 3상의 합이 0인 것과 같은 이유로 합이 0이 된다.

이 성질의 결과는 크다.

- 3상 회전기는 토크 맥동이 없다.
- 평형 운전 중인 3상 컨버터는 DC 링크에 120 Hz 전력 맥동이 없다. 단상 인버터는 이 맥동을 DC 링크 커패시터로 받아야 한다.
- 전압·전류가 불평형이면(역상분이 생기면) 3상 합에도 120 Hz 맥동이 다시 나타난다. 고장 중 거동을 볼 때 중요하다([[C11-전류-제한과-고장]]).

**pu 표기.** 상전압과 상전류를 각각 진폭 기준 pu로 쓰면 합은 $\tfrac32 VI\cos\varphi$ 다. 이 강좌는 이 $\tfrac32$ 를 전력 기준값에 흡수한다.

$$
P = \frac23\left(v_a i_a + v_b i_b + v_c i_c\right) = V I\cos\varphi \quad [\text{pu}]
$$

즉 정격 상전압 진폭(1 pu)과 정격 상전류 진폭(1 pu)이 같은 위상이면 $P$ = 1 pu, 곧 정격 전력이다. 실효값으로 쓰면 $3V_{rms}I_{rms}$ 와 같은 값이다. 기준값의 정식 정의는 [[C02-공간벡터-좌표변환-pu]]에 있다.

> [!note]- 유도: 3상 순시전력의 합
> 곱을 합으로 바꾸는 공식 $\cos A\cos B = \tfrac12[\cos(A-B) + \cos(A+B)]$ 를 쓴다. $k$ 상에서 $A = \omega t - 120°k$, $B = \omega t - 120°k - \varphi$ 이므로
> $$v_k i_k = \frac{VI}{2}\left[\cos\varphi + \cos(2\omega t - 240°k - \varphi)\right]$$
> 둘째 항의 위상은 $k$ 에 따라 0°, −240°, −480° 다. 이는 0°, +120°, −120° 와 같으므로 세 항의 합은 $\mathrm{Re}\{e^{j(2\omega t - \varphi)}(1 + a + a^2)\} = 0$.
> 남는 것은 $3\cdot\tfrac{VI}{2}\cos\varphi = \tfrac32 VI\cos\varphi$ 다.

### 1.5 무효전력

3상 합 $p(t)$ 가 일정하다고 해서 각 상에서 에너지가 오가지 않는 것은 아니다. 한 상의 순시전력을 다시 쓰면

$$
p_a(t) = \frac{VI}{2}\Big[\cos\varphi\,(1 + \cos 2\omega t) + \sin\varphi\,\sin 2\omega t\Big]
$$

첫째 항은 늘 0 이상인, 실제로 전달되는 전력이다. 둘째 항은 평균이 0이고 전원과 부하 사이를 왕복한다. 이 왕복 성분의 크기를 나타내는 양이 **무효전력(reactive power)** 이다.

$$
Q = V I\sin\varphi \quad [\text{pu}], \qquad S = \sqrt{P^2 + Q^2}
$$

- 3상에서는 왕복 성분이 상끼리 상쇄되어 합에는 보이지 않는다. 그래도 선로와 필터에는 전류가 흐르고, 전압 강하를 만든다.
- **부호 관례(출력 기준)**: 인버터가 내보내는 전류가 전압보다 **뒤지면** $Q > 0$, 계통에 무효전력을 **공급**한다. 앞서면 $Q < 0$, 흡수한다. 시뮬레이터의 $P, Q$ 도 출력을 양으로 잡는다.
- 유도성 계통에서 전압 크기는 주로 $Q$ 가, 위상과 주파수는 주로 $P$ 가 좌우한다. GFL의 Q 제어와 GFM의 Q–V 드룹이 여기서 나온다([[C08-GFL-PLL로-따라가기]], [[C09-GFM-위상을-만들기]]).
- 컨버터 전류 한계는 $P$ 가 아니라 전류 크기에 걸린다. 전압이 1 pu이면 $|I| = S$ 다. 전류 한계 1.2 pu는 $S \le 1.2$ pu와 같다.

무효전력도 순시값으로 계산할 수 있다. 각 상 전류에 "나머지 두 상의 선간전압"을 곱한다.

$$
q(t) = \frac{1}{\sqrt3}\Big[(v_b - v_c)\,i_a + (v_c - v_a)\,i_b + (v_a - v_b)\,i_c\Big], \qquad Q = \frac23\,q
$$

> [!note]- 유도: 순시 무효전력 식이 $Q$ 를 주는 이유
> $\bar V_b - \bar V_c = V(a^2 - a) = -j\sqrt3\,V$ 이므로 $v_b - v_c = \sqrt3\,V\sin\omega t$ 다. 즉 $v_a$ 보다 90° 뒤진 크기 $\sqrt3 V$ 의 전압이다.
> $$\frac{1}{\sqrt3}(v_b - v_c)\,i_a = V\sin\omega t\cdot I\cos(\omega t - \varphi) = \frac{VI}{2}\left[\sin\varphi + \sin(2\omega t - \varphi)\right]$$
> 세 상을 더하면 2배 주파수 항은 1.4절과 같은 이유로 상쇄되고 $q = \tfrac32 VI\sin\varphi$ 가 남는다. 따라서 $Q = \tfrac23 q = VI\sin\varphi$.

## 3. Python 실습

### 3.1 numpy로 맥동 상쇄 확인

```python
# 저장소 루트에서 실행 (numpy만 사용)
import numpy as np

w = 2 * np.pi * 60
t = np.linspace(0, 2 / 60, 2000, endpoint=False)   # 두 주기
V, I, phi = 1.0, 1.0, np.arccos(0.8)           # 진폭 [pu], 역률 0.8 지상
sh = np.array([0, -2 * np.pi / 3, 2 * np.pi / 3])[:, None]   # a, b, c
v = V * np.cos(w * t + sh)                     # 3 × N
i = I * np.cos(w * t + sh - phi)

p_phase = v * i                                # 상별 순시전력
p = p_phase.sum(axis=0)                        # 3상 합
print("a상 순시전력 범위:", p_phase[0].min().round(3), "~", p_phase[0].max().round(3))
print("3상 합 범위    :", p.min().round(6), "~", p.max().round(6))
print("P [pu] = (2/3)·합 =", (2 / 3 * p).mean().round(4), " (이론 V·I·cosφ =", round(V * I * np.cos(phi), 4), ")")

# 순시 무효전력: 선간전압과 다른 상 전류의 곱 (전력이론의 고전 식)
va, vb, vc = v
ia, ib, ic = i
q = ((vb - vc) * ia + (vc - va) * ib + (va - vb) * ic) / np.sqrt(3)
print("Q [pu] = (2/3)·q  =", (2 / 3 * q).mean().round(4), " (이론 V·I·sinφ =", round(V * I * np.sin(phi), 4), ")")
print("선간 진폭 =", np.abs(va - vb).max().round(4), ", 상 실효값 =", np.sqrt((va**2).mean()).round(4))
```

실행 결과:

```text
a상 순시전력 범위: -0.1 ~ 0.9
3상 합 범위    : 1.2 ~ 1.2
P [pu] = (2/3)·합 = 0.8  (이론 V·I·cosφ = 0.8 )
Q [pu] = (2/3)·q  = 0.6  (이론 V·I·sinφ = 0.6 )
선간 진폭 = 1.732 , 상 실효값 = 0.7071
```

### 3.2 시뮬레이터 기록값으로 순시전력 계산

[[simulation/emt/README|EMT 시뮬레이션]]은 상별 순시값 `va, vb, vc, ia, ib, ic` 를 기록한다. 이것으로 직접 $P$ 를 계산해 모델의 `P` 와 비교한다.

```python
# 저장소 루트에서 실행 (평균값 모델, 첫 실행 약 10 s, 이후 캐시 사용)
import sys; sys.path.insert(0, "simulation/emt")
import numpy as np
from gfm_gfl_emt import Params, Scenario, simulate, steady_state

p = Params(converter="average")                 # 스위칭 리플 없는 평균값 모델
x0 = steady_state("GFM", p, dt=10e-6)           # P_ref = 0.5 pu 정상상태
r = simulate("GFM", p, Scenario(t_end=0.05), dt=10e-6, x0=x0)
o = {k: np.asarray(r[k]) for k in ("t", "P", "va", "vb", "vc", "ia", "ib", "ic")}

p3 = o["va"] * o["ia"] + o["vb"] * o["ib"] + o["vc"] * o["ic"]
print(f"(2/3)·Σ v·i : 평균 {np.mean(2/3*p3):.4f} pu, 표준편차 {np.std(2/3*p3):.1e}")
print(f"모델의 P    : 평균 {np.mean(o['P']):.4f} pu")
print(f"a상 v·i     : {np.min(o['va']*o['ia']):.3f} ~ {np.max(o['va']*o['ia']):.3f}  (120 Hz 맥동)")
```

실행 결과:

```text
(2/3)·Σ v·i : 평균 0.5019 pu, 표준편차 2.9e-05
모델의 P    : 평균 0.4994 pu
a상 v·i     : -0.002 ~ 0.504  (120 Hz 맥동)
```

한 상의 곱은 0 ~ 0.5 사이를 오가지만, $\tfrac23$ 을 곱한 3상 합은 0.502 로 거의 일정하다. 모델의 `P`(0.499)와 0.0025 pu 차이가 나는 것은 **측정점** 때문이다. 기록값 `ia` 는 컨버터측(필터 인덕터 $L_f$) 전류이고, 모델의 `P` 는 PCC 전압과 **변압기 전류**로 계산한다. 그 차이는 필터 커패시터 지로로 흐르는 전류다. 어디서 재야 하는지는 [[C05-필터-변압기-측정점]]에서 다룬다.

> [!tip] 해볼 것
> - 3.1에서 `phi` 를 90° 로 바꾸면 $P$ = 0 이 되고 상별 맥동만 남는다. 무효전력만 오가는 상태다.
> - 3.1에서 b상 진폭만 0.8로 줄여 불평형을 만든다. 3상 합에 120 Hz 맥동(약 1.02 ~ 1.22)이 나타난다.
> - 3.2에서 `"GFM"` 을 `"GFL"` 로 바꿔도 같은 결론이 나오는지 확인한다.

## 4. 흔한 오해

> [!warning] 오해: 3상 순시전력이 일정하니 무효전력은 없다
> 합이 일정한 것은 각 상의 왕복 성분이 서로 상쇄되기 때문이다. 각 상의 선로와 필터에는 무효 성분의 전류가 그대로 흐르고, 전압 강하와 전류 한계 소모를 만든다.

> [!warning] 오해: 1 pu 전압은 선간 실효값이다
> 명판 관례일 뿐이다. 이 강좌는 1 pu = 정격 **상전압 진폭**으로 정한다. 같은 운전점을 가리키므로 비율(0.9 pu, 1.1 pu 등)은 그대로 쓸 수 있다. 진폭 측정값과 실효값 기준을 섞지만 않으면 된다.

> [!warning] 오해: 3상 전력은 "3 × 상전압 진폭 × 상전류 진폭"이다
> 진폭으로 쓰면 $\tfrac32 VI\cos\varphi$, 실효값으로 쓰면 $3V_{rms}I_{rms}\cos\varphi$ 다. 강좌의 pu는 이 계수를 기준값에 흡수하여 $P = VI\cos\varphi$ 로 쓴다.

## 5. 확인 문제

1. $v_a = \cos\omega t$ pu 인 평형 정상분 3상에서 선간전압 $v_{bc}$ 의 진폭과 위상은?

> [!success]- 답
> $\bar V_{bc} = \bar V_b - \bar V_c = a^2 - a = -j\sqrt3$. 진폭 $\sqrt3 \approx 1.732$ pu, 위상 −90° 다. 즉 $v_{bc} = \sqrt3\cos(\omega t - 90°)$ pu. $v_b$ 보다 30° 앞선다는 규칙과도 맞는다.

2. 상전압 진폭 1 pu, 상전류 진폭 0.5 pu, 전류가 전압보다 60° 뒤진다(출력 기준). $P$, $Q$ 와 $v_a i_a + v_b i_b + v_c i_c$ 는?

> [!success]- 답
> $P = 1\times 0.5\times\cos 60° = 0.25$ pu, $Q = 1\times 0.5\times\sin 60° \approx 0.433$ pu(공급). 순시 곱의 합은 $\tfrac32 \times 0.25 = 0.375$ 로 일정하다.

3. 한 상 순시전력의 맥동 주파수는? 3상 합이 일정하지 않게 되는 경우를 두 가지 들어라.

> [!success]- 답
> 120 Hz(계통 주파수의 2배). 전압이나 전류가 불평형일 때(역상분 존재), 그리고 고조파가 있을 때 3상 합에도 맥동이 생긴다.
