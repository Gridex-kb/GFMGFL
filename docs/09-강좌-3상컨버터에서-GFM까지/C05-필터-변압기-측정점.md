# C05. 필터·변압기·측정점

> [!abstract] 이 강의에서 답할 질문
> 컨버터가 만든 PWM 전압은 어떻게 매끈한 계통 전류가 되는가? 그리고 제어기는 **어디의** 전류와 전압을 재야 하는가?

> [!info] 학습 목표
> - L 필터와 LCL 필터의 차이, LCL 공진 주파수와 수동 댐핑(Rd)의 역할을 설명할 수 있다.
> - pu 값만으로 LCL 공진 주파수와 스위칭 전류 리플의 상한을 계산할 수 있다.
> - 컨버터측 전류는 전류 제어·제한에, 변압기 전류와 PCC 전압은 전력·전압·위상 측정에 쓰는 이유를 설명할 수 있다.

## 1. 핵심 개념

### 1.1 L 필터에서 LCL 필터로

2레벨 VSC의 극전압은 ±V_dc/2(= ±1.128 pu)를 오가는 펄스다([[C03-2레벨-VSC]]). 이 펄스를 전류로 바꾸는 가장 간단한 방법은 직렬 인덕터 하나, 즉 **L 필터**다. 인덕터 임피던스는 주파수에 비례하므로 5 kHz 성분을 기본파보다 약 83배 강하게 막는다. 다만 감쇠 기울기가 -20 dB/dec뿐이라, 리플을 충분히 줄이려면 인덕터가 커지고 기본파 전압강하도 커진다.

**LCL 필터**는 컨버터측 인덕터 $L_f$, 커패시터 $C_f$, 계통측 인덕터 $L_g$로 이루어진다. 공진 주파수 위에서는 -60 dB/dec로 떨어지므로, 같은 감쇠를 더 작은 인덕터로 얻는다. 이 강좌의 기준 설비는 변압기 누설 리액턴스를 $L_g$로 쓴다.

| 요소 | 모델 값 [pu] | 역할 |
|---|---|---|
| $L_f$, $R_f$ | 0.20, 0.005 | 컨버터측 인덕터. 전류 제어 대상 |
| $C_f$ | 0.05 (서셉턴스) | 리플 전류의 우회로 |
| $R_d$ | 2.0 | 커패시터 직렬 댐핑 저항 |
| $L_t$, $R_t$ | 0.10, 0.005 | 변압기 누설. LCL의 $L_g$ 역할 |
| PCC 분로 | 0.03 (저항성) | 보조 부하·손실 등가 |

### 1.2 공진 주파수

pu에서 인덕터는 리액턴스 $X$로, 커패시터는 서셉턴스 $B$로 적는다. 둘 다 정격 주파수 $f_0$ = 60 Hz에서 잰 값이다. 이때 LCL 공진 주파수는 다음과 같다.

$$
f_{res} = f_0\sqrt{\frac{L_f + L_g}{L_f\,L_g\,C_f}}
\qquad (L_f, L_g, C_f\ \text{는 pu 리액턴스·서셉턴스})
$$

- 강한 계통($L_g = L_t$ = 0.1 pu): $f_{res} = 60\sqrt{0.3/(0.2\cdot0.1\cdot0.05)}$ ≈ **1039 Hz**.
- SCR 3 계통 리액턴스까지 더하면($L_g$ = 0.1 + 1/3 ≈ 0.433 pu) 약 **725 Hz**로 내려간다.

즉 공진 주파수는 하드웨어만의 값이 아니다. **계통이 약할수록 내려와** 전류 제어 대역(800 Hz)에 가까워진다. 이것이 약계통 고주파 상호작용의 한 뿌리다([[C10-약계통과-제어-상호작용]]).

> [!note]- 유도: pu 리액턴스로 쓴 LCL 공진 주파수
> 컨버터 전압에서 계통측 전류까지의 전달함수를 계통 전압을 단락하고 저항을 무시해 구하면
> $$\frac{i_g}{v_c} = \frac{1}{s^3 L_f L_g C + s(L_f + L_g)}$$
> 분모가 0이 되는 $s = j\omega$에서 $\omega_{res}^2 = \dfrac{L_f + L_g}{L_f L_g C}$ 이다. 여기서 $L, C$는 SI 단위의 인덕턴스·커패시턴스다.
>
> pu 리액턴스 $X = \omega_b L / Z_b$, 서셉턴스 $B = \omega_b C Z_b$ 이므로 $L = X Z_b/\omega_b$, $C = B/(\omega_b Z_b)$ 를 대입하면 $Z_b$ 가 모두 지워진다.
> $$\omega_{res}^2 = \omega_b^2\,\frac{X_f + X_g}{X_f X_g B}
> \;\Rightarrow\; f_{res} = f_0\sqrt{\frac{X_f + X_g}{X_f X_g B}}$$
> 같은 식을 "정격 주파수에서 $L_f \parallel L_g$ 의 리액턴스와 $C_f$ 의 리액턴스가 같아지는 고조파 차수 $h_{res}$" 로 읽어도 된다: $h_{res}^2 = 1/(X_{eq} B)$, $X_{eq} = X_f X_g/(X_f+X_g)$.

### 1.3 수동 댐핑: 커패시터 직렬 저항 $R_d$

손실이 거의 없는 LCL은 공진점에서 이득이 수십 dB 솟는다(그림 1의 주황색). 전류 제어나 계통 쪽 성분이 이 주파수를 조금만 건드려도 크게 울린다. 가장 단순한 대책이 커패시터에 직렬로 저항 $R_d$를 넣는 **수동 댐핑(passive damping)**이다.

- 공진 주파수에서 커패시터 리액턴스는 $1/(h_{res} B) = 1/(17.3\times0.05)$ ≈ 1.15 pu다. 모델의 $R_d$ = 2 pu는 이보다 커서 공진 봉우리가 사라질 만큼 강하게 감쇠한다.
- 대가는 고주파 감쇠다. 커패시터 가지가 저항처럼 보이면서 공진 위의 기울기가 -60에서 -40 dB/dec 쪽으로 완만해진다. 5 kHz에서 감쇠는 $R_d$ = 0일 때 약 -55 dB, $R_d$ = 2 pu일 때 약 -37 dB, L 필터(0.3 pu)는 약 -28 dB다.
- 이 프로젝트에서 $R_d$를 2 pu로 정한 이유는 따로 있다. GFM 가상 어드미턴스에 순시 PCC 전압을 넣었더니 $R_d$ = 1 pu에서 약 500 Hz로 불안정했고, 2 pu로 늘려 해결했다([[simulation/emt/README|EMT 시뮬레이션]] 교훈 5).

능동 댐핑(제어로 가상 저항을 만드는 방법)도 있지만, 이 강좌는 수동 댐핑만 쓴다.

### 1.4 스위칭 전류 리플

인덕터 전류의 리플 크기는 펄스 전압과 인덕턴스로 정해진다. 단상 하프브리지에서 듀티 0.5일 때 가장 크며, 그 **상한**은

$$
\Delta i_{pp} \le \frac{V_{dc}}{4\,L\,f_{sw}},\qquad L = \frac{L_{f,pu}}{\omega_b}\ [\text{s}]
$$

이다. pu 리액턴스를 $\omega_b$로 나누면 "초" 단위의 인덕턴스가 되어 pu 전압과 바로 계산된다. 기준 설비 값($V_{dc}$ = 2.256 pu, $L_f$ = 0.2 pu, 5 kHz)을 넣으면

$$
\Delta i_{pp} \le \frac{2.256}{4\times(0.2/377)\times5000} \approx 0.21\ \text{pu}
$$

다. EMT 모델에서 실제로 잰 리플은 **약 0.11 pu 피크-피크**로 상한의 절반 정도다. 3상에서는 중성점 전압이 극전압의 공통 성분을 흡수하므로, 인덕터에 걸리는 상전압 펄스가 극전압보다 작게 쪼개지기 때문이다. 그러니 위 식은 "이보다 크지는 않다"는 설계용 상한으로만 쓴다.

> [!note]- 유도: 하프브리지 리플 상한
> 극전압이 $+V_{dc}/2$ 인 구간(듀티 $D$)에서 인덕터에 걸리는 전압은 $V_{dc}/2 - v$ 이다 ($v$ = 한 주기 평균 출력 전압). 한 주기 동안 전류 증가분은
> $$\Delta i = \frac{(V_{dc}/2 - v)\,D}{L f_{sw}}$$
> 평균 전압 관계 $v = (2D-1)V_{dc}/2$ 에서 $m = v/(V_{dc}/2)$ 로 두면 $D = (1+m)/2$ 이고
> $$\Delta i = \frac{V_{dc}}{4 L f_{sw}}\,(1 - m^2)$$
> $m = 0$ (듀티 0.5)에서 최대 $V_{dc}/(4 L f_{sw})$ 가 된다. pu 전압을 쓰려면 $L$ 을 pu 리액턴스/$\omega_b$ 로 넣으면 된다 ($v = L\,di/dt$ 에서 pu 리액턴스 $X$ 는 $\omega_b L$ 에 해당).

### 1.5 변압기

변압기는 세 가지 일을 한다.

1. **전압 맞추기**: 컨버터 쪽 저압을 계통 전압으로 올린다. pu에서는 권선비가 사라지고 누설 리액턴스 $L_t$ = 0.1 pu만 남는다.
2. **LCL의 계통측 인덕터**: 별도의 $L_g$ 없이 누설 리액턴스가 그 역할을 한다.
3. **경계**: 고압측이 PCC(Point of Common Coupling, 공통 연결점)다. 계통코드의 요구(전력, 전압, 고장 응답)는 PCC 기준이다. Δ-Y 결선이면 컨버터의 영상분 전압이 계통으로 넘어가지 않는다.

### 1.6 측정점 설계

같은 회로에도 측정할 수 있는 곳이 여럿이다. 이 강좌의 모델은 다음처럼 나눈다.

| 측정 | 위치 | 쓰는 곳 |
|---|---|---|
| 컨버터측 전류 $i_f$ | $L_f$ | **전류 제어, 전류 제한**만 |
| 변압기 전류 $i_t$ | 변압기 | P, Q 계산 |
| PCC 전압 $v_{pcc}$ | 변압기 고압측 | P, Q, \|V\|, GFL의 PLL, GFM의 가상 어드미턴스 입력 |

- **전류 제어는 $i_f$여야 한다.** 컨버터 전압이 직접 움직이는 상태가 $i_f$이고, 반도체에 흐르는 전류도 $i_f$다. 과전류로부터 소자를 지키려면 이 전류를 제한해야 한다.
- **전력·전압·위상은 리플이 없는 곳에서 잰다.** $i_f$에는 0.11 pu p-p 리플이 있고, 필터 단자 전압에도 $R_d$에 흐르는 리플 전류가 섞인다. 반송파 꼭짓점 샘플링([[C06-디지털-제어와-지연]])으로 리플 평균을 잡더라도, 스위칭 측대파 일부는 샘플링에서 낮은 주파수로 **에일리어싱(aliasing)**된다. 2·f_sw(10 kHz) 주변의 측대파는 10 kHz 샘플링에서 360 Hz 배수로 접혀 들어온다. LCL을 지난 변압기 전류와 PCC 전압에는 이 성분이 훨씬 적다.
- **PCC는 계통이 보는 곳이다.** 외부 루프의 목적(P·Q 지령 추종, PCC 전압 지지)이 PCC 기준이므로, 측정도 그곳에서 하는 것이 자연스럽다.

> [!example] 프로젝트 사례: 측정점 하나가 안정도 판정을 바꿨다
> EMT 모델 초기에는 $L_f$ 전류와 필터 단자 전압으로 전력을 쟀다. 그러자 360·720·1080 Hz 에일리어싱 잡음(표준편차 약 0.010 pu)이 측정 전력에 섞였다. 진동 판정 함수가 이 잡음을 제어 진동으로 읽어, **실제로는 안정한 강계통 GFM을 불안정으로 판정**했다.
> 측정을 변압기 전류와 PCC 전압으로 옮기자 잡음이 약 0.004 pu로 줄었고, 판정이 바로잡혔다. 같은 비교를 지금 모델로 다시 하면(그림 3, 실습 3) 0.006 대 0.003 pu다. 당시 기록과 절대값은 다르지만, 측정점만 바꿔도 잡음이 절반 정도로 준다는 경향은 같다.
> 교훈: 제어 안정도를 논하기 전에 **측정이 무엇을 보고 있는지** 먼저 확인한다.

## 3. Python 실습

```python
# 저장소 루트에서 실행 (CPU 약 10 s, 처음 한 번은 초기화 포함 약 15 s)
import sys; sys.path.insert(0, "simulation/emt")
import numpy as np
import gfm_gfl_emt as emt
from gfm_gfl_emt import Params, Scenario, simulate, steady_state, replace

p = Params()
# 1) LCL 공진 주파수: 강한 계통(변압기만) / SCR 3 계통 리액턴스 포함
for Lg in (p.Lt, p.Lt + 1 / p.scr):
    f_res = p.f0 * np.sqrt((p.Lf + Lg) / (p.Lf * Lg * p.Cf))
    print(f"Lg = {Lg:.3f} pu -> f_res = {f_res:.0f} Hz")

# 2) 리플 상한 (단상 하프브리지, 듀티 0.5)
vdc = p.V_dc / p.V_base_peak            # 2.256 pu
L_s = p.Lf / p.wb                       # pu 리액턴스 -> '초' 단위 인덕턴스
print(f"리플 상한 = {vdc / (4 * L_s * p.f_sw):.3f} pu p-p")

# 3) EMT: 샘플 시점마다 두 측정점으로 P 를 계산해 비교 (강계통 GFM)
log = []
class Logged(emt.Inverter):
    def sample(self, t, x):
        v_term, v_pcc, i_t = self.network(t, x)[:3]
        i_f = complex(x[emt.IF_RE], x[emt.IF_IM])
        log.append(((v_pcc * i_t.conjugate()).real, (v_term * i_f.conjugate()).real))
        super().sample(t, x)
emt.Inverter = Logged

pa = Params(converter="average", scr=10.0)
x0 = steady_state("GFM", pa, t_init=1.5, dt=1e-5)          # 평균값 모델로 빠르게 초기화
r = simulate("GFM", replace(pa, converter="switching"), Scenario(t_end=0.2),
             x0=x0, hires=(0.15, 0.2))                       # 0.15~0.2 s 는 2 µs 파형 기록
P = np.array(log[1000:])                                     # 0.1 s 이후
print(f"σ(P) 변압기·PCC = {P[:, 0].std():.4f} pu, Lf·필터단자 = {P[:, 1].std():.4f} pu")

ia = np.array(r["hires"]["ia"])                              # Lf 전류 a상, 2 µs
sm = np.convolve(ia, np.ones(100) / 100, mode="same")        # 반송파 한 주기(200 µs) 이동평균
rip = (ia - sm)[100:-100]
print(f"측정 리플 = {rip.max() - rip.min():.3f} pu p-p")
```

출력 예: 공진 1039 Hz / 725 Hz, 리플 상한 0.213 pu, σ(P) 0.0033 대 0.0063 pu, 측정 리플 0.111 pu.

> [!tip] 해볼 것
> - `Params(Lf=0.15)` 또는 `Lf=0.3`으로 바꿔 리플 상한과 측정 리플이 $1/L_f$에 비례하는지 확인한다(공진 주파수도 함께 바뀐다).
> - `Rd=1.0`으로 줄여 그림 1의 해석식으로 공진 봉우리를 다시 그려 본다.
> - `scr`을 1.5~10으로 바꿔 $L_g = L_t + 1/\text{SCR}$일 때 공진 주파수가 800 Hz 전류 제어 대역에 얼마나 다가오는지 표로 만든다.

## 4. 흔한 오해

> [!warning] 오해: 컨버터측 전류가 가장 빠르고 정확하니 전력도 그걸로 재면 된다
> 컨버터측 전류는 전류 제어·제한에는 반드시 필요하지만, 리플과 에일리어싱 잡음이 가장 큰 신호이기도 하다. 전력·전압·위상처럼 외부 루프가 쓰는 양은 LCL을 지난 변압기 전류와 PCC 전압으로 재야 한다. 이 프로젝트에서는 측정점 선택이 안정도 판정 자체를 바꿨다.

> [!warning] 오해: LCL 공진 주파수는 필터 부품으로 정해진 고정값이다
> 계통 리액턴스가 $L_g$에 더해지므로, 계통이 약할수록 공진 주파수가 내려간다(강계통 1039 Hz → SCR 3에서 725 Hz). 필터 설계는 운전할 SCR 범위 전체에서 확인해야 한다.

> [!warning] 오해: 댐핑 저항은 클수록 안전하다
> $R_d$를 키우면 공진은 잘 눌리지만 고주파 감쇠가 줄어든다(5 kHz에서 -55 → -37 dB). 커패시터 가지의 손실도 는다. 공진 억제와 리플 감쇠 사이의 절충이다.

## 5. 확인 문제

1. $L_f$ = 0.2 pu, $C_f$ = 0.05 pu, $L_g$ = 0.1 + 1/SCR pu일 때, SCR = 2에서 LCL 공진 주파수는 약 몇 Hz인가?

> [!success]- 답
> $L_g$ = 0.6 pu. $f_{res} = 60\sqrt{0.8/(0.2\times0.6\times0.05)} = 60\sqrt{133.3}$ ≈ **693 Hz**. 전류 제어 대역 800 Hz보다 낮아진다.

2. $V_{dc}$ = 2.256 pu, $L_f$ = 0.2 pu, $f_{sw}$ = 5 kHz에서 리플 상한이 약 0.21 pu인데 모델 측정값은 약 0.11 pu다. 상한 식을 "실제 리플"로 쓰면 안 되는 이유는?

> [!success]- 답
> 상한 식은 단상 하프브리지, 듀티 0.5, 인덕터 반대편 전압 일정이라는 가장 나쁜 조건의 값이다. 3상에서는 중성점 전압이 극전압의 공통 성분을 흡수해 인덕터에 걸리는 상전압 펄스가 작아지고, 리플은 듀티에 따라 달라진다. 그래서 설계 여유를 잡는 상한으로만 쓰고, 실제 값은 EMT로 확인한다.

3. GFM의 가상 어드미턴스 입력 전압과 VSM의 전력 측정을 필터 단자 전압과 $L_f$ 전류로 바꾸면 어떤 일이 생길 수 있는가?

> [!success]- 답
> 측정 전력에 스위칭 측대파의 에일리어싱 잡음(360 Hz 배수)이 섞여 VSM과 가상 어드미턴스 루프로 들어간다. 이 프로젝트에서는 잡음이 약 0.004 → 0.010 pu로 커져, 안정한 강계통 GFM이 불안정으로 판정되었다. 잡음이 실제 제어 루프로도 들어가므로, 판정만이 아니라 제어 자체도 흔들린다.
