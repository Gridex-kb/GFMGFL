# C06. 디지털 제어와 지연

> [!abstract] 이 강의에서 답할 질문
> 디지털 제어기는 언제 재고, 언제 내보내며, 그 사이의 지연은 얼마이고 무엇을 망가뜨리는가?

> [!info] 학습 목표
> - 반송파 꼭짓점 동기 샘플링과 2회 갱신이 무엇인지, 왜 리플 평균값을 얻는지 설명할 수 있다.
> - 계산 지연 1 Ts와 PWM 지연 0.5 Ts를 합한 약 1.5 Ts(150 µs)의 위상 지연을 주파수별로 계산할 수 있다.
> - 샘플-홀드된 측정을 어느 각도로 dq 변환하고, 출력 전압을 어느 각도로 되돌려야 하는지 설명할 수 있다.

## 1. 핵심 개념

### 1.1 반송파 꼭짓점 동기 샘플링

삼각파 반송파 PWM에서 컨버터측 전류 리플은 반송파의 꼭짓점(골·마루)을 중심으로 대칭이다. 펄스의 한가운데에서 전류가 리플의 평균값을 지나므로, **꼭짓점에서 샘플링하면 아날로그 필터 없이 리플 평균값**을 얻는다([[C04-변조-SPWM-SVPWM]]의 반송파 그림 참고). 이것을 반송파 동기 샘플링(synchronous sampling)이라고 한다.

- **2회 갱신(double update)**: 골과 마루 양쪽에서 샘플링하고 듀티를 갱신한다. 스위칭 5 kHz면 샘플링은 10 kHz, $T_s$ = **100 µs**다.
- 평균값을 정확히 잡는 것은 듀티가 샘플 사이에서 거의 변하지 않을 때다. 스위칭 측대파 일부는 여전히 에일리어싱되어 들어온다([[C05-필터-변압기-측정점]]).

### 1.2 1.5 샘플 지연

샘플 $k$에서 잰 값으로 계산한 전압 지령은 계산이 끝난 뒤, 다음 샘플 $k+1$부터 PWM에 적용된다. 적용된 지령은 $T_s$ 동안 유지되므로(영차 홀드), 그 효과의 무게중심은 구간의 가운데다. 합하면

$$
T_d \approx \underbrace{T_s}_{\text{계산}} + \underbrace{0.5\,T_s}_{\text{PWM 홀드}} = 1.5\,T_s = 150\ \mu\text{s}
$$

지연은 크기를 바꾸지 않고 위상만 늦춘다. 주파수 $f$에서 위상 지연은

$$
\phi_d = \omega T_d = 360^\circ\cdot f\,T_d
$$

로 주파수에 비례한다. 100 Hz에서 5.4°, 400 Hz에서 21.6°, **800 Hz에서 43.2°**다. 전류 제어 교차주파수(800 Hz)에서 위상여유의 거의 절반을 지연이 먹는다.

> [!note]- 유도: 영차 홀드가 0.5 Ts 지연인 이유
> 영차 홀드의 전달함수는 $G_{zoh}(s) = \dfrac{1 - e^{-sT_s}}{sT_s}$ 이다. $s = j\omega$ 를 넣고 $e^{-j\omega T_s/2}$ 를 묶으면
> $$G_{zoh}(j\omega) = e^{-j\omega T_s/2}\,\frac{\sin(\omega T_s/2)}{\omega T_s/2}$$
> 크기는 $\omega T_s \ll 1$ 에서 거의 1이고, 위상은 정확히 $-\omega T_s/2$, 즉 0.5 $T_s$ 순수 지연이다. 계산 지연 $e^{-sT_s}$ 와 곱하면 $e^{-1.5 sT_s}$ 가 된다.

### 1.3 제어 대역폭의 한계

지연이 있는 루프의 교차주파수 $f_c$에서 지연은 $360^\circ f_c T_d$를 소비한다. PI 영점이 약 10°를 더 쓰고 위상여유를 35~45° 남기려면 $f_c T_d$가 대략 0.1 근처여야 한다. 그래서 흔히 **"전류 제어 대역폭은 샘플링 주파수의 1/10 정도"**라고 말한다. 이것은 **경험칙**이다. 정확한 한계는 지연 크기, 원하는 위상여유, 플랜트 모양으로 계산해야 한다. 이 강좌의 800 Hz(샘플링 10 kHz의 1/12.5)는 위상여유 약 35°를 남긴다([[C07-전류-제어]]).

### 1.4 각도 처리: 측정은 샘플 시점의 θ로, 출력은 지연만큼 앞당겨

dq 제어에서 각도 $\theta$는 계속 회전한다(60 Hz면 100 µs에 약 2.16°). 그런데 측정값은 샘플 시점 $t_k$에 홀드되어 있다. 그래서 두 가지 규칙이 필요하다.

1. **변환**: 홀드된 측정은 **샘플 시점의 각** $\theta_k$로 dq 변환한다. 다음 샘플까지 계속 도는 $\theta(t)$로 변환하면, 고정된 벡터를 도는 좌표에서 보게 되어 $v_q$가 샘플 주기 안에서 톱니처럼 흐른다.
2. **출력**: 계산한 $v^*_{dq}$는 1.5 $T_s$ 뒤에 효과를 내므로, 그동안 회전할 각만큼 앞당겨 αβ로 되돌린다.

$$
v^*_{\alpha\beta} = v^*_{dq}\,e^{\,j(\theta_k + 1.5\,\omega T_s)}
$$

모델 코드에서는 `sample()`이 `th_hold = x[TH_C]`로 샘플 시점 각을 저장하고, `deriv()`가 `th_out = th_ctl + 1.5·Ts·ωb·w_c`로 출력 각을 만든다.

> [!note]- 유도: 연속 θ로 변환했을 때의 PLL 주파수 오프셋
> 계통 전압 $|v| = 1$ pu, PLL이 정확히 추종해 $\theta_k$ 에서 $v_q = 0$ 이라고 하자. 홀드된 벡터를 연속 각 $\theta(t) = \theta_k + \omega(t - t_k)$ 로 변환하면
> $$v_q(t) = -\sin\big(\omega(t - t_k)\big) \approx -\omega(t - t_k),\quad t_k \le t < t_k + T_s$$
> 한 주기 평균은 $-\omega T_s/2$ 다. PI의 적분기는 평균 $v_q$ 를 0으로 만들도록 움직이므로, 정상상태에서 샘플 시점 값은 $v_q(t_k) = +\omega T_s/2$ 가 된다(위상 오차 $\omega T_s/2$ ≈ 1.08°).
> PLL 주파수 출력은 $\omega_{pll} = 1 + k_p v_q + x_I$ 이고 평균 주파수는 정확해야 하므로 $x_I$ ≈ 0, 따라서 샘플 시점(제어·기록 시점)의 주파수는
> $$\Delta\omega_{pll}(t_k) = k_p\,\frac{\omega T_s}{2}\ \text{[pu]}$$
> 만큼 어긋난다. PLL 50 Hz, ζ = 0.707이면 $k_p = 2\zeta\omega_n/\omega_b$ ≈ 1.18, $\omega T_s$ = 377 × 100 µs ≈ 0.0377 rad 이므로 $\Delta f$ ≈ 1.18 × 0.0377/2 × 60 ≈ **1.33 Hz**.

> [!example] 프로젝트 사례: PLL이 61.3 Hz를 가리켰다
> 스위칭 모델에 샘플-홀드를 처음 넣었을 때, 홀드된 측정을 연속 회전하는 $\theta$로 변환했다. 그러자 $v_q$가 샘플 주기 안에서 톱니처럼 흘렀고, PLL 주파수에 $k_p\omega T_s/2$만큼 오프셋이 생겼다. PLL 50 Hz 설정에서 60 Hz 계통을 **약 1.3 Hz 높게** 읽었다. 이 측정 주파수를 드룹·합성관성에 쓰면 그대로 출력 오차가 된다.
> 해결은 두 가지였다. 측정 변환은 샘플 시점 $\theta_k$로 고정하고(`th_hold`), 출력 전압에는 1.5 $T_s$ 회전각을 보상했다. 그림 3과 실습에서 이 버그를 다시 만들어 볼 수 있다(61.35 Hz → 60.00 Hz).

### 1.5 평균값 모델의 1차 지연 근사와 무엇이 다른가

모델의 `converter="average"`는 스위칭과 샘플링을 없애고, 지연을 1차 지연 $1/(1 + sT_d)$ ($T_d$ = 150 µs)로 근사한다. 빠르고 회귀 테스트에 좋지만 차이를 알고 써야 한다.

| 항목 | 스위칭 모델 (실제 디지털 제어) | 평균값 모델 |
|---|---|---|
| 지연 | 순수 지연 $e^{-1.5sT_s}$: 위상만, 끝없이 증가 | 1차 지연: 크기 감쇠, 위상은 90°에서 멈춤 |
| 800 Hz 위상 | 43° | 37° (크기 -2 dB) |
| 샘플링·리플·에일리어싱 | 있음 | 없음 |
| 각도 처리 | $\theta_k$ 변환 + 1.5 $T_s$ 보상 필요 | 연속 θ, 보상 없음 |

1차 근사는 고주파에서 위상 지연을 덜 주고 이득은 깎아 주므로 **낙관적**이다. 예를 들어 PCC 전압 순시 피드포워드를 켠 GFM은 SCR 2에서 평균값 모델로는 안정했지만, 스위칭 모델에서는 약 560 Hz 진동이 자라 지속되었다([[C07-전류-제어]] 그림 2). 고주파 안정도 결론은 순수 지연이 들어간 모델로 확인해야 한다([[C13-EMT-모델링-실습]]).

## 3. Python 실습

```python
# 저장소 루트에서 실행 (CPU 약 10 s, 처음 한 번은 초기화 포함 약 15 s)
import sys, math; sys.path.insert(0, "simulation/emt")
import numpy as np
import gfm_gfl_emt as emt
from gfm_gfl_emt import Params, Scenario, simulate, steady_state, replace

p = Params(f_pll=50.0, scr=5.0)
Ts = 1 / (2 * p.f_sw)                   # 100 µs
Td = 1.5 * Ts                           # 150 µs
for f in (100, 400, 800):
    w = 2 * math.pi * f
    print(f"{f:4d} Hz: 순수 지연 {math.degrees(w*Td):5.1f}°, 1차 근사 {math.degrees(math.atan(w*Td)):5.1f}°")

kp = 2 * p.pll_zeta * 2 * math.pi * p.f_pll / p.wb
print(f"예상 오프셋 kp·ω·Ts/2 = {kp * p.wb * Ts / 2 * p.f0:.2f} Hz")

class ContTheta(emt.Inverter):
    """잘못된 각도 처리: 홀드된 측정을 연속 회전 θ 로 dq 변환"""
    def deriv(self, t, x):
        self.th_hold = x[emt.TH_C]
        return super().deriv(t, x)

Orig = emt.Inverter
x0 = steady_state("GFL", replace(p, converter="average"), t_init=1.5, dt=1e-5)
for name, cls in (("샘플 시점 θ", Orig), ("연속 θ", ContTheta)):
    emt.Inverter = cls
    r = simulate("GFL", p, Scenario(t_end=0.15), x0=x0)
    f = np.array(r["freq"])[500:]                            # 0.05 s 이후
    d = np.array(r["delta_deg"])[500:]
    print(f"{name}: PLL 주파수 평균 {f.mean():.2f} Hz, 위상차 {d.mean():.2f}°")
emt.Inverter = Orig
```

출력 예: 800 Hz에서 43.2° 대 37.0°, 예상 오프셋 1.33 Hz, 샘플 시점 θ 60.00 Hz / 5.44°, 연속 θ 61.35 Hz / 4.35°. 위상차 차이 1.09°가 유도에서 구한 $\omega T_s/2$ ≈ 1.08°와 맞는다.

> [!tip] 해볼 것
> - `f_pll`을 20 Hz로 낮춰 오프셋이 $k_p$에 비례해 줄어드는지(약 0.54 Hz) 확인한다.
> - `scr=2.0`으로 바꿔도 오프셋이 거의 같은지(약 1.35 Hz) 본다. 계통 강도와 무관한, 순수한 디지털 처리 오차다.
> - `ContTheta.deriv` 안에서 `self.Ts`를 잠시 0으로 바꿨다가 되돌리면 출력 지연 보상까지 뺀 버전이 된다. 주파수 오프셋은 거의 그대로다. 오프셋의 원인은 출력이 아니라 측정 변환 쪽이라는 뜻이다.

## 4. 흔한 오해

> [!warning] 오해: 샘플링이 10 kHz이니 지연은 100 µs다
> 계산 지연 1 샘플에 PWM 영차 홀드 0.5 샘플이 더해져 약 1.5 Ts = 150 µs다. 계산을 샘플 직후 끝내고 즉시 갱신하는 구조라도 영차 홀드의 0.5 Ts는 남는다.

> [!warning] 오해: 각도는 어차피 연속적으로 도니, 아무 시점의 θ로 변환해도 된다
> 측정이 샘플-홀드되어 있으면 변환 각도도 샘플 시점에 고정해야 한다. 연속 θ를 쓰면 $v_q$에 톱니가 생겨, 이 프로젝트에서는 PLL 주파수가 약 1.3 Hz 어긋났다. 출력 쪽은 반대로 1.5 Ts만큼 앞선 각으로 되돌려야 한다.

> [!warning] 오해: 평균값 모델에도 지연을 넣었으니 디지털 제어와 같다
> 1차 지연 근사는 고주파에서 위상을 덜 늦추고 크기를 깎는다. 수백 Hz 이상 상호작용을 따질 때는 낙관적인 결론이 나올 수 있다.

## 5. 확인 문제

1. 스위칭 5 kHz, 2회 갱신, 1샘플 계산 지연일 때 1 kHz에서의 위상 지연은?

> [!success]- 답
> $T_s$ = 100 µs, $T_d$ = 150 µs. $\phi_d = 360° \times 1000 \times 150\times10^{-6}$ = **54°**.

2. 꼭짓점 샘플링이 리플 평균값을 주는 이유와, 그래도 측정 잡음이 남는 이유를 각각 한 문장으로 쓰라.

> [!success]- 답
> 대칭 삼각파 PWM에서 리플은 펄스 가운데(반송파 꼭짓점)를 중심으로 대칭이라 그 순간 전류가 평균값을 지난다. 그러나 듀티가 샘플 사이에 변하고 스위칭 측대파 일부가 샘플링 주파수 배수 근처에 있어, 낮은 주파수(이 설비에서는 360 Hz 배수)로 에일리어싱되어 남는다.

3. PLL 20 Hz(ζ = 0.707)에서 연속 θ 변환 버그가 있을 때, 샘플 시점의 PLL 주파수 오프셋은 약 몇 Hz인가?

> [!success]- 답
> $k_p = 2\times0.707\times2\pi\times20/377$ ≈ 0.471. $\Delta f = k_p\,\omega_b T_s/2 \times 60 = 0.471\times0.0377/2\times60$ ≈ **0.53 Hz**.
