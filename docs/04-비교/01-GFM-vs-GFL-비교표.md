# GFM vs GFL 비교표

> 요약: 계통형성(GFM)과 계통추종(GFL)을 동작 원리, 계통 영향, 하드웨어, 비용, 적용처 관점에서 한 장에 비교한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 1. 종합 비교

| 항목 | GFL (Grid-Following) | GFM (Grid-Forming) |
|---|---|---|
| 계통에서 본 등가 | 제어된 **전류원** | 임피던스 뒤의 **전압원** |
| 동기화 방식 | PLL이 계통 전압 위상 측정 | 유효전력 균형으로 자체 위상 생성 |
| 전압·주파수 기준 | 외부(계통)에 의존 | 스스로 설정, 다른 전원과 동기화 |
| 외란 응답 | 측정 → 연산 → 응답 (50~500 ms) | 물리적 즉시 응답 (수 ms, 측정 불필요) |
| 관성 | 없음 (합성관성은 측정 기반) | VSM: 명시적 H, Droop: 암묵적 |
| 위상 점프 | PLL 재추종 과도, 오응답·탈락 위험 | 즉시 동기화 전력, 복원력 제공 |
| 약계통(SCR<2) | 불안정 (PLL 음저항) | 안정, 오히려 유리 |
| 강계통(SCR>5) | 안정, 단순 | 전력 루프 안정 여유 감소 → 가상 임피던스 필요 |
| 계통강도 | 소비 | 공급 |
| 블랙스타트·단독운전 | 불가 | 가능 (설계 시) |
| 고장 전류 | 제어로 주입 (지연 수 ms~수십 ms) | 즉시 ($I_{max}$ 내), 제한 설계 필수 |
| 전류 제한 | 자연스러움 | 가장 어려운 설계 과제 (제한 중 동기 유지) |
| 전력 지령 추종 정확도 | 높음 | 드룹 특성상 계통 상태에 따라 변동 (상위 제어로 보정) |
| 고조파·불평형 | 전류제어 대역 밖 성분 흡수 못함 | 수동 흡수 (전류 여유 소모) |
| 과부하 여유 요구 | 작음 | 1.2~1.5 pu 수 초 권장 |
| 에너지 버퍼 | 불필요(PV 가능) | 필요 (ESS 유리, PV는 출력 여유) |
| 모델링·검토 | RMS 모델 대체로 가능 | EMT 모델 요구 (대부분 계통운영자) |
| 보호 협조 | 기존 관행 | 단락전류 작음 → 보완 필요 |
| 성숙도 | 수십 년 대량 보급 | 2018~ 송전급 실증, 2023~ 상업 보급 확대 |
| 비용 | 기준 | PCS 과부하 설계·검증 비용 추가 (ESS 기준 수 % 수준으로 보고되나 사업별 상이, 확인 필요) |

## 2. 응답 시간대 비교

```
 외란 발생
 │
 ├─ 0~5 ms      GFM: 전압원 특성으로 전류 즉시 변화 (위상점프·고장전류)
 │              GFL: PLL/필터 과도 시작
 ├─ 5~50 ms     GFM: 관성 응답 (ΔP ∝ RoCoF)
 │              GFL: 측정 창 진행 중
 ├─ 50~500 ms   GFM: 드룹/댐핑 응답 정착
 │              GFL: FFR·합성관성·동적 무효전류 응답 개시
 └─ 0.5 s~      양쪽: 1차 주파수제어, 전압 제어 정착
```

## 3. 제어 구조 비교 (한눈에)

```
 GFL                                  GFM
 v_abc ─▶ PLL ─▶ θ                    P,Q 측정 ─▶ 전력동기화 ─▶ θ, E
 P*,Q* ─▶ i_dq* ─▶ 전류PI ─▶ PWM       E∠θ ─▶ (가상Z) ─▶ 전압루프 ─▶ 전류제한 ─▶ 전류PI ─▶ PWM
```

## 4. 어떤 자원에 어느 모드가 맞는가

| 자원 | GFL | GFM | 비고 |
|---|---|---|---|
| 대용량 BESS | ○ | **◎** | 에너지 버퍼 있어 가장 적합. 2027~ 국내 요건 대상 |
| 태양광 | ◎ | △ | 출력 여유 확보(curtail) 또는 DC 결합 ESS 필요 |
| 풍력(풀컨버터) | ◎ | ○ | 회전자 운동에너지 활용, 제조사 GFM 옵션 등장 |
| HVDC (VSC) | ○ | ○ | 수전단 약계통에 GFM 유리 |
| STATCOM | ○ | △ | 에너지 결합(E-STATCOM) 시 GFM 가능 |
| 소형 분산자원(주택) | ◎ | △ | 단독운전 검출 규정과의 정합 과제 |
| 마이크로그리드 마스터 | ✗ | ◎ | 필수 |

## 5. 혼합 계통에서의 "비율" 논의

- 계통 전체를 GFM으로 바꿀 필요는 없다. 연구·운영 경험은 지역별 IBR 용량의 **일정 비율(문헌별 20~40 % 수준, 계통 구조에 따라 크게 다름)** 이 GFM이면 나머지 GFL이 안정화된다고 보고한다. (수치는 참고용, 계통별 EMT 검토 필요)
- 호주 AEMO, 영국 NESO, 미국 MISO 등은 **신규 BESS를 GFM으로 의무화/권고**하여 점진적으로 비율을 높이는 전략을 택했다. → [국제 표준·해외 계통코드](../05-표준-계통코드/01-국제표준-해외계통코드.md)
