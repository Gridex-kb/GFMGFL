# 하이브리드 · 모드 전환 · 혼합 계통

> 요약: GFL과 GFM이 공존하는 현실 계통에서의 상호작용, GFL↔GFM 모드 전환, 플랜트 단위 혼합 구성, 운영 관점의 과제를 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- 현실은 **동기기 + GFL + GFM 혼합 계통**이다. GFM은 GFL을 안정화하지만, GFM끼리 또는 GFM–GFL 사이에도 새로운 상호작용 모드가 생길 수 있다.
- 하나의 인버터가 상황에 따라 GFL↔GFM을 **전환**하는 하이브리드 설계가 있다. 전환 시 과도(bumpless transfer)와 전환 판단 기준이 핵심.
- 플랜트 단위에서는 "일부 PCS만 GFM"으로 구성하거나, PV+ESS 하이브리드에서 ESS PCS만 GFM으로 두는 구성이 흔하다.
- 운영자는 GFM 비율, 배치 위치(약계통 지점 우선), 파라미터 조정(H, D, 드룹) 정책을 정해야 한다.

## 1. GFM–GFL 상호작용

| 상호작용 | 메커니즘 | 대책 |
|---|---|---|
| GFM이 GFL 안정화 | GFM의 낮은 임피던스가 GFL PLL 루프의 유효 SCR을 높임 | GFM을 약계통 지점에 우선 배치 |
| GFL이 GFM 동기화 방해 | GFL의 음저항 특성이 GFM 전력 루프의 댐핑을 깎음 | GFM 댐핑(D) 강화, GFL PLL 대역폭 축소 |
| GFM–GFM 순환 전력 | 드룹·가상 임피던스 불일치, 설정값 차이 | 드룹 계수 정합, 가상 임피던스, 2차 제어(통신) |
| GFM–동기기 진동 | 두 "전압원"이 로터각 진동 모드 공유 | GFM에 가상 PSS, D 조정 |
| 전류 제한 중 상호작용 | 고장 중 GFM이 전류원화 → 주변 GFL 기준 전압 상실 | 가상 임피던스 기반 제한, 지역 GFM 용량 확보 |

## 2. 모드 전환 (GFL ↔ GFM)

### 2.1 왜 전환하나
- 강계통·급전 추종이 중요한 평상시에는 GFL, 약계통·고장·단독운전 시 GFM.
- 기존 GFL 자산을 펌웨어로 업그레이드하되 위험을 줄이기 위해.
- 고장 중 전류 제한 구현을 GFL 모드로 단순화하기 위해 (PSC 계열).

### 2.2 전환 설계 요소
1. **판단 신호**: SCR 추정, 전압/주파수 이탈, 계통 분리 검출(차단기 상태), 상위 지령.
2. **상태 초기화**: 전환 순간 GFM의 $\theta$, $E$를 현재 PLL 위상·PCC 전압으로 초기화 → 과도 최소화.
3. **적분기 처리**: 안티와인드업, bumpless transfer.
4. **복귀 조건**: 히스테리시스, 최소 유지 시간.
5. **검증**: 전환 중 전류 피크, 전력 과도, 재발 진동 EMT 확인.

### 2.3 "항상 GFM" vs "전환형"
| | 항상 GFM | 전환형 |
|---|---|---|
| 계통 기여 | 상시 | 조건부 |
| 설계 복잡도 | 전류 제한 중 안정성 과제 | 전환 로직·과도 과제 |
| 계통코드 적합성 | 유리 (GB, AEMO는 상시 GFM 특성 요구) | 일부 요건 충족 어려움 |
| 급전 정확도 | 상위 제어로 보정 | 우수 |

대부분의 계통코드는 "정상 운전 중 상시 전압원 특성"을 요구하므로 **전환형은 계통서비스 인정에 불리**할 수 있다.

## 3. 플랜트 단위 혼합 구성

```
 PV+ESS 하이브리드 플랜트
 ┌─ PV 인버터 (GFL) ×N ─┐
 ├─ PV 인버터 (GFL) ×N ─┼── 집전 ── 승압 ── PCC
 └─ ESS PCS (GFM) ×M ───┘
```

- ESS PCS만 GFM으로 두어 플랜트 전체에 전압 기준 제공. PV GFL은 그 기준을 따름.
- 비율 설계: 플랜트 내 GFM 용량이 GFL 용량 대비 충분해야(문헌별 ≥ 20~30 %, 확인 필요) 플랜트 내부 약계통 문제 해소.
- 플랜트 제어기(PPC)는 GFM의 드룹 특성과 충돌하지 않도록 느린 설정값 조정만 수행.

## 4. 운영자 관점의 정책 과제

1. **배치**: 어디에 GFM을 두어야 효과가 큰가 — 약계통 지점, 재생에너지 밀집 지역, HVDC 수전단.
2. **파라미터 표준화**: H, D, 드룹, 가상 임피던스 범위를 계통코드로 정하되 제조사 자유도 보장.
3. **모델 제출**: EMT 블랙박스 모델 + 범용 모델(REGFM 등) 요구.
4. **서비스 보상**: 관성·계통강도·블랙스타트를 별도 시장/계약으로 보상(영국 Stability Pathfinder, 호주 system strength, 독일 Momentanreserve 등).
5. **단계적 의무화**: 신규 BESS부터 GFM 요건 적용 (MISO 2025~, 한국 2027~ 등). → [표준·계통코드](../05-표준-계통코드/)
