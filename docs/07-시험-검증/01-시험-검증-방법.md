# 시험·검증 방법 — 모델링, HIL, 성능시험

> 요약: GFM 인버터의 성능을 설계 단계(시뮬레이션) → 공장/실험실(HIL, PHIL, 전력 시험) → 현장(연계 시험, 상업운전 모니터링) 순으로 어떻게 검증하는지 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- GFM 검증의 핵심은 "**측정 없이 전압원처럼 즉시 반응하는가**"를 보여주는 것이다. 대표 시험: 위상 점프, 주파수 램프(RoCoF), 전압 스텝, 고장(FRT), 약계통(SCR 스윕), 병렬운전, 단독운전/블랙스타트.
- 계통운영자는 **EMT 모델**(제조사 블랙박스 + 범용 모델)을 요구하며, 시험 결과와 모델이 일치(model validation)해야 한다.
- 실험실 단계에서는 **CHIL(제어기 HIL)** 과 **PHIL(전력 HIL)**, 계통 시뮬레이터(grid simulator)를 이용한 약계통 모사가 표준 절차가 되고 있다.
- 국제적으로 IEEE P2800.2(IBR 적합성 시험), NERC GFM 기능 규격의 시험 목록, AEMO GFM 시험 가이드, GB GC0137 컴플라이언스 절차가 참고 틀이다. → 세부 문서명/연도는 [국제 표준·해외 계통코드](../05-표준-계통코드/01-국제표준-해외계통코드.md)

## 1. 검증 단계

```
 설계                실험실                       현장
 EMT 시뮬레이션 → CHIL(RTDS/OPAL-RT) → PHIL / 그리드시뮬레이터 → 공장 시험 → 연계 시험 → 운전 모니터링
   (모델)           (실제 제어기)       (실제 PCS, 축소/정격)     (FAT)      (SAT, 계통코드)   (PMU, 이벤트 분석)
```

## 2. 모델링

| 모델 | 용도 | 비고 |
|---|---|---|
| 상세 스위칭 EMT | 제어 설계, 필터 공진 | 느림, 소규모 |
| 평균값 EMT | 계통 연계 검토, 상호작용 | 대부분 계통운영자 요구 (PSCAD, PowerFactory EMT) |
| 제조사 블랙박스 DLL | 실제 제어 코드 | AEMO, ERCOT, NESO 등 필수 제출 |
| 범용 GFM 모델 (WECC REGFM_A1 Droop형, REGFM_B1 VSM형) | 계획 연구, 비교 | 파라미터 공개, PSS/E·PSLF 등 |
| RMS(페이저) | 대규모 안정도 | GFM 전류 제한·고속 동역학 근사 → 보수적 사용 |
| 임피던스 모델 (주파수 스캔) | 소신호 상호작용 | 측정 가능 (PHIL 주파수 스캔) |

**모델 검증(validation)**: 동일 시험(위상 점프·전압 스텝 등)을 실물과 모델에서 수행하고 응답을 비교. 허용 오차 기준은 각 계통코드/IEEE 2800 계열 문서 참고.

## 3. 대표 시험 항목과 판정 포인트

| 시험 | 방법 | 보는 것 |
|---|---|---|
| **위상 점프** | 계통 시뮬레이터로 PCC 위상 ±Δφ 스텝 (예: 10°, 30°, 60°) | 첫 5 ms 내 전류 응답, 유효전력 피크, 재동기 시간, 전류 제한 거동 |
| **주파수 램프 / RoCoF** | f를 ±1~4 Hz/s로 램프 | ΔP가 RoCoF에 비례(관성)하고 지연 없이 시작하는지, 등가 H 추정 |
| **주파수 스텝 / 드룹** | f 스텝 | 정상상태 ΔP = 드룹 계수 확인 |
| **전압 스텝** | V ±5~10 % 스텝 | 무효전류 즉시 응답, Q–V 드룹, 전압 루프 정착 |
| **FRT (3상·불평형)** | 잔류전압 0~0.9 pu, 수십~수백 ms | 전류 제한 유지, 무효전류 우선, 동기 유지, 고장 제거 후 회복 시간 |
| **약계통 SCR 스윕** | 계통 임피던스 증가 (SCR 10 → 1) | 안정 유지 한계, 진동 댐핑비 |
| **강계통** | SCR 매우 높게 | 전력 루프 안정성, 가상 임피던스 효과 |
| **고조파·불평형 전압** | 왜곡 전압 인가 | 흡수 전류, 열, 제한 루프 동작 |
| **병렬운전** | 2대 이상 GFM, 통신 없음 | 전력 분담, 순환전류, 진동 |
| **단독운전 / 부하 스텝** | 계통 분리 후 부하 투입·차단 | V/f 유지, 돌입 대응 |
| **블랙스타트** | 무전압 변압기 여자 | 돌입전류, 전압 램프, 보조전원 |
| **모드 전환** (해당 시) | GFL↔GFM | 과도 크기 |
| **임피던스 스캔** | 소신호 주입 | 출력 임피던스 수동성, 음저항 대역 |

## 4. HIL 구성

- **CHIL (Controller HIL)**: 실제 제어기(DSP/FPGA)와 실시간 시뮬레이터(RTDS, OPAL-RT, Typhoon, dSPACE)를 연결. 계통 조건을 무제한 변경 가능, 전력 하드웨어 위험 없음. 제어 로직·펌웨어 검증의 표준.
- **PHIL (Power HIL)**: 실제 PCS(축소 또는 정격)를 그리드 시뮬레이터(증폭기)에 연결하고 계통 모델을 실시간으로 돌려 상호작용 재현. 약계통·고장 시험 가능. 국내 LS일렉트릭 천안 10 MW 검증설비 등이 이 유형(세부·출처는 [국내 동향](../06-실증-사례/02-국내-동향.md)).
- **주파수 스캔**: PHIL/CHIL에서 소신호 주입으로 출력 임피던스 측정 → 임피던스 기반 안정도 평가.

## 5. 현장 시험과 상업운전 모니터링

- **연계(SAT) 시험**: 계통운영자 입회, 지령 스텝, 무효전력 응답, 가능하면 실제 계통 이벤트 대기. 위상 점프를 현장에서 인위적으로 만들기는 어려워 **모델 검증**에 의존.
- **PMU/고속 기록**: 1 kHz 이상 샘플링 기록장치로 실제 외란 응답 수집, 모델과 비교(호주 AEMO가 Hornsdale 등에서 수행).
- **성능 지표**: 응답 지연(ms), 등가 관성(MW·s), 위상 점프 전력(MW/도), 댐핑비, FRT 성공률.
