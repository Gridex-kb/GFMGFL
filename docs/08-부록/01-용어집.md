# 용어집

> 요약: 이 지식창고에서 쓰는 GFM/GFL·전력계통 용어를 가나다/알파벳 순으로 정리한다. 새 용어는 여기에 추가한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

| 용어 (영문) | 한글 | 설명 |
|---|---|---|
| AVR (Automatic Voltage Regulator) | 자동전압조정기 | 동기기 여자 제어. GFM의 Q–V 루프에 대응 |
| BESS (Battery Energy Storage System) | 배터리 에너지저장장치 | 배터리 + PCS + EMS. GFM 적용의 주 대상 |
| Black start | 블랙스타트 | 전계통 정전 후 외부 전원 없이 기동·전압 형성 |
| CHIL / PHIL | 제어기/전력 HIL | 실시간 시뮬레이터에 제어기 또는 실제 전력장치를 연결한 시험 |
| CSCR / WSCR / ESCR | 복합/가중/유효 단락비 | 다수 IBR 지역의 보정 SCR 지표 |
| Damping | 댐핑, 감쇠 | 진동을 줄이는 힘. 댐핑비 ζ로 정량화 |
| Droop | 드룹 | 주파수(전압) 변화에 비례해 출력을 바꾸는 특성. P–f, Q–V |
| dVOC (dispatchable Virtual Oscillator Control) | 디스패치 가능 가상 진동자 제어 | 비선형 진동자 기반 GFM 기법 |
| EMT (Electromagnetic Transient) | 전자기 과도 | µs 단위 상세 시뮬레이션 (PSCAD 등) |
| ESS (Energy Storage System) | 에너지저장장치 | 넓은 의미의 저장장치 |
| E-STATCOM | 에너지 저장형 STATCOM | STATCOM + 저장장치, GFM 운영 가능 |
| FFR (Fast Frequency Response) | 고속 주파수 응답 | 주파수 측정 후 수백 ms 내 응답하는 서비스 |
| FRT (Fault Ride-Through) / LVRT / HVRT | 고장 통과 / 저전압·고전압 통과 | 고장 중 접속을 유지하는 능력·요건 |
| GFL (Grid-Following) | 계통추종 | PLL로 계통 위상을 추종하는 전류원형 인버터 |
| GFM (Grid-Forming) | 계통형성 | 자체 전압·위상을 만드는 전압원형 인버터 |
| Grid code | 계통코드, 계통연계기준 | 계통운영자가 정한 연계 기술요건 |
| H (inertia constant) | 관성상수 | 정격용량 대비 회전 운동에너지 [s] |
| HVDC (VSC) | 전압형 고압직류송전 | 인버터 기반 HVDC. GFM 제어 가능 |
| IBR (Inverter-Based Resource) | 인버터 기반 자원 | 태양광·풍력·ESS·HVDC 등 전력전자로 연계되는 자원 |
| Inertia / inertial response | 관성 / 관성 응답 | 주파수 변화율에 비례한 즉각적 에너지 교환 |
| Islanding | 단독운전 | 계통에서 분리된 채 전압·주파수를 유지하는 운전 |
| LCL filter | LCL 필터 | 인버터 출력 스위칭 고조파 제거 필터 |
| Matching control | 매칭 제어 | DC링크 전압을 주파수에 매칭하는 GFM 기법 |
| Momentary cessation | 순간 정지 | 전압 이상 시 인버터가 전류 주입을 멈추는 거동 (NERC 지적) |
| PCC (Point of Common Coupling) | 공통연계점 | 계통과의 연계 지점 |
| PCS (Power Conversion System) | 전력변환장치 | ESS용 양방향 인버터 |
| Phase jump | 위상 점프 | 계통 이벤트로 PCC 전압 위상이 급변하는 현상 |
| PLL (Phase-Locked Loop) | 위상동기루프 | 계통 전압 위상·주파수 추정 루프 |
| PMU (Phasor Measurement Unit) | 페이저 측정장치 | 동기 페이저 고속 기록 |
| PPC (Power Plant Controller) | 발전단지 제어기 | 플랜트 단위 P/Q/V 제어 |
| PSC (Power Synchronization Control) | 전력 동기화 제어 | HVDC용으로 제안된 GFM 기법 |
| PSS (Power System Stabilizer) | 전력계통안정화장치 | 동기기 진동 댐핑 보조 제어 |
| RoCoF (Rate of Change of Frequency) | 주파수 변화율 | Hz/s. 관성이 작을수록 커짐 |
| RMS model | 페이저 모델 | 기본파 근사 안정도 모델 (PSS/E 등) |
| SCR (Short-Circuit Ratio) | 단락비 | 연계점 단락용량 / IBR 정격. 계통강도 지표 |
| SOC (State of Charge) | 충전상태 | 배터리 잔존 용량 비율 |
| Synchronous condenser | 동기조상기 | 무부하 동기기. 관성·단락전류·전압 지원 |
| Synchronverter | 싱크로나버터 | 동기기 모델을 통째로 구현한 GFM 기법 (Zhong) |
| Synthetic inertia | 합성 관성 | 주파수 측정 기반 유사 관성 응답 (GFL) |
| System strength | 계통강도 | 전압 파형을 유지하는 계통의 능력 (SCR 등으로 표현) |
| Transient stability | 과도 안정도 | 큰 외란 후 동기 유지 능력 |
| UFLS (Under-Frequency Load Shedding) | 저주파수 부하차단 | 주파수 급락 시 부하 차단 보호 |
| Virtual impedance | 가상 임피던스 | 제어로 만든 출력 임피던스. 디커플링·전류제한 |
| VSC (Voltage Source Converter) | 전압형 컨버터 | DC→AC 변환의 기본 회로 |
| VSM / VSG (Virtual Synchronous Machine/Generator) | 가상동기기 | 스윙 방정식을 구현한 GFM 기법 |
| Weak grid | 약계통 | SCR이 낮은 계통 (통상 < 3) |
