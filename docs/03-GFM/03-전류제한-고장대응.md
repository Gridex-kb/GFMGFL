# 전류 제한과 고장 대응 (Fault Ride-Through)

> 요약: GFM 설계에서 가장 어려운 문제인 과전류 제한과, 제한 중 동기화 유지·고장 통과(FRT)·고장 전류 기여를 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

- 인버터는 1.1~1.5 pu(순간 ≤2 pu) 이상 전류를 흘릴 수 없다. 전압원인 GFM이 고장 시 그대로 두면 수 pu 전류가 흐르므로 **반드시 제한**해야 한다.
- 제한 방식은 크게 ① 전류 기준 포화(Current reference saturation), ② 가상 임피던스(Virtual impedance), ③ 전압 기준 제한, ④ 고장 시 GFL(전류원) 모드 전환, 그리고 이들의 조합이다.
- 제한이 걸리면 전압원 특성이 사라져 **동기화 상실(transient instability)** 위험이 생긴다. 제한 중 위상 동역학을 어떻게 유지하느냐가 핵심이며, 고장 제거 후 **재동기(re-synchronization)** 설계도 필요하다.
- 계통코드(GB GC0137, AEMO, NERC 등)는 GFM이 고장 중에도 전압원 특성을 최대한 유지하고 제한 전류 내에서 무효전류를 공급하도록 요구한다.

## 1. 문제의 구조

```
 정상: E∠δ ──Z_v+Z_f── V_pcc    I = (E - V_pcc)/Z  ≈ 1 pu
 고장: V_pcc → 0.2 pu           I → 수 pu  ✗ (반도체 파괴)
```

고장 깊이·임피던스에 따라 요구 전류가 한계를 넘는 순간 어떤 식으로든 **전류원**이 되어야 하고, 이 순간 "전압원이기 때문에 생기던" 동기화 토크가 바뀐다.

## 2. 제한 기법

### 2.1 전류 기준 포화 (Current Reference Limiting)
캐스케이드 구조에서 전압 루프 출력 $i^*$를 제한.
- **크기 제한(circular)**: $\|i^*\| \le I_{max}$, 각도 유지.
- **dq 우선순위**: $i_q$(무효) 우선 후 $i_d$ 잔여, 또는 반대. 계통코드가 고장 중 무효전류 우선을 요구하는 경우가 많다.
- 문제: 제한 중 전압 루프 적분기 와인드업, 전압원 특성 상실 → 안티와인드업과 함께 위상 루프 보정 필요.

### 2.2 가상 임피던스 (Threshold/Transient Virtual Impedance)
$$Z_v = Z_{v0} + k_{vi}\,\max(0,\; \|i\| - I_{th})$$
전류가 임계값을 넘으면 가상 임피던스를 키워 **전압원 특성을 유지한 채** 전류를 줄인다. 전압원 동작이 보존되어 동기화 안정성에 유리. 단, 임피던스 설계가 고장 조건에 민감하고 완전한 하드 리밋은 아니므로 2.1과 병용.

### 2.3 전압 기준 제한 / 전압 루프 비활성화
고장 시 전압 루프를 끄고 전류 루프만 남겨 사실상 GFL로 동작 (PSC 계열). 간단하나 동기화는 보조 PLL에 의존.

### 2.4 비교

| 기법 | 전압원 특성 유지 | 하드 리밋 | 구현 난이도 | 비고 |
|---|---|---|---|---|
| 전류 기준 포화 | ✗ (제한 중 전류원) | ○ | 낮음 | 가장 흔함, 동기화 보정 필수 |
| 가상 임피던스 | ○ | △ | 중간 | 포화와 병용 권장 |
| 모드 전환(GFL) | ✗ | ○ | 중간 | 재동기 로직 필요 |
| 혼합 | ○ (대부분) | ○ | 높음 | 상용 제품 다수 |

## 3. 제한 중 과도 안정도 (Transient Stability)

전류 제한 상태에서 인버터 출력 전력은 $P \approx V_{pcc} I_{max}\cos\phi$ 로 고정되고, 위상 루프는 $P^* - P$가 양수이면 계속 가속한다. 평형점이 없으면 동기기 탈조처럼 **$\delta$가 발산**한다.

대책:
- 제한 중 **유효전력 기준 $P^*$를 실제 출력 가능치로 낮춤**(실현 가능 평형점 복구).
- 위상 루프에 **고장 중 주파수 동결** 또는 보조 PLL 추종.
- 가상 임피던스로 전압원 특성 유지(가장 자연스러움).
- 댐핑 항 강화 (VSM의 $D$ 증가).
- 유효전력 우선 대신 **전류 각도 유지**(전압과 전류 위상 관계 보존) 방식 제한.

평가는 등면적법 확장 또는 EMT 시뮬레이션으로 한다. 계통코드 시험 항목에 "고장 중/후 동기 유지"가 포함된다.

## 4. 고장 전류 기여와 보호

- GFM은 전압 강하 즉시(서브사이클) 전류를 공급하지만 크기는 $I_{max}$(1.2~2 pu)로 제한된다. 동기기(5~7 pu)와 달리 과전류 계전기 감도가 떨어질 수 있다.
- 보호 설계 보완: 전압 기반 보호, 차동 보호, 통신 기반 보호, 역방향 전력 보호, 적응형 정정.
- 불평형 고장: 역상 전류 주입 여부·양 역시 계통코드 항목(IEEE 2800, VDE 4120 등). GFM은 역상 전압에 대해서도 전압원처럼 반응하므로 자연스럽게 역상 전류가 흐르며, 이를 제한하는 역상 제어 루프가 필요하다.

## 5. 고장 제거 후 재동기 및 회복

- 고장 제거 시 PCC 전압이 급상승 + 위상 점프. 제한 해제 시 **전압원 복귀 과도**에서 과전류 재발 가능 → 제한 해제를 점진적으로.
- 전압 루프 적분기 초기화(bumpless transfer).
- 계통코드: 고장 제거 후 유효전력 회복 시간(예: 수백 ms 이내 90 % 회복)과 진동 억제 요구.

## 6. 설계 체크리스트

- [ ] $I_{max}$ 와 과부하 지속시간(열) 사양 확정 — 하드웨어 선정과 연계
- [ ] 제한 기법 조합 및 P/Q 우선순위 결정 (계통코드 확인)
- [ ] 제한 중 위상 루프 거동 (동결/보정/가상 임피던스) 정의
- [ ] 3상·불평형 고장, 깊이(0~0.9 pu), 지속시간(계통코드 FRT 곡선)별 EMT 검증
- [ ] 고장 제거 후 재동기·회복 시간, 과전류 재발 확인
- [ ] 보호 협조 검토 (단락전류 기여량 제공)
