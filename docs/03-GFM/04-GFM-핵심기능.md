# GFM 핵심 기능 — 관성, 위상 점프 응답, 블랙스타트, 단독운전

> 요약: 계통운영자·계통코드가 GFM에 요구하는 기능들을 하나씩 정의하고, 각 기능의 물리적 의미와 하드웨어 요구 사항을 정리한다.
> 최종 갱신: 2026-11-01 · 상태: 초안

## 핵심 요약 (TL;DR)

각국 규격(NERC, UNIFI, AEMO, GB GC0137, ENTSO-E 등)이 공통으로 꼽는 GFM 기능은 다음과 같다. 세부 수치·문서명은 [표준·계통코드](../05-표준-계통코드/)에 있다.

| 기능 | 한 줄 정의 | 필요 자원 |
|---|---|---|
| 전압원 동작 (voltage source behaviour) | 외란 직후 수 ms 동안 내부 전압의 크기·위상을 유지 | 제어 |
| 관성 응답 / 능동 관성 | 주파수 변화에 비례해 측정 없이 유효전력 교환 | 에너지 버퍼, 과부하 여유 |
| 위상 점프 응답 (phase jump power) | PCC 위상 급변 시 즉시 유효전력 응답으로 복원력 제공 | 과부하 여유 |
| 고장 전류 기여 | 전압 강하 즉시 제한 전류 내 무효전류 공급 | 전류 한계 |
| 댐핑 (전력 진동 감쇠) | 저주파·아임계 진동에 양의 댐핑 | 제어 |
| 전압 강성 / 계통강도 제공 | 낮은 출력 임피던스로 주변 GFL 안정화 | 제어, 용량 |
| 블랙스타트 | 무전압 상태에서 전압 형성, 변압기 여자, 부하 투입 | 보조전원, 돌입 전류 여유 |
| 단독운전(islanding) 및 재동기 | 계통 분리 후 V/f 유지, 복귀 시 동기투입 | 에너지 버퍼, 동기장치 |
| 고조파·불평형 흡수 | 전압원 특성으로 왜곡 전류 자연 흡수 | 전류 여유 |

## 1. 전압원 동작 (Voltage Source Behaviour)

- 정의(요지): 외란 발생 후 적어도 수 전기 주기 동안 내부 기전력 $E\angle\theta$가 크게 변하지 않는다. 즉, PCC 전압 변화 → 전류 변화가 **제어 지연 없이** 발생한다.
- 측정 방법: 전압 스텝/위상 스텝 시험 후 처음 수 ms의 전류 응답을 전압원 모델과 비교. GB GC0137은 "5 ms 이내" 수준의 즉시 응답을 전제로 한다(구체 수치는 문서 확인).
- 왜 중요한가: 이 특성이 관성·위상 점프 응답·고장 전류의 **공통 근원**이다.

## 2. 관성 응답 (Inertial Response)

- 스윙 방정식의 $2H\,\dot f/f_0 = \Delta P$ 에 따라 RoCoF에 비례한 전력을 교환. VSM은 $H$로 명시, Droop은 LPF로 암묵적.
- 필요한 에너지: RoCoF 1 Hz/s, H = 5 s이면 즉시 $\Delta P \approx 2H\cdot RoCoF/f_0 = 0.2$ pu. 이 전력을 수 초간 유지하려면 ESS 용량의 작은 일부만으로 충분하지만, **순간 과부하 여유**(예: 1.2~1.5 pu for 수 초)가 있어야 상향 응답이 가능하다.
- 양방향: 과주파수 시 흡수(충전) 능력도 필요 → SOC 관리.
- 계통코드 예: GB는 관성 기여량(MW·s)을 입찰 항목으로, AEMO는 "응답 속도·크기"를 평가.

## 3. 위상 점프 응답 (Phase Jump Power)

- 송전선 트립·대형 부하 차단으로 PCC 위상이 $\Delta\phi$ 만큼 뛰면, GFM은 $\Delta P \approx \dfrac{EV}{X}\sin(\Delta\phi)$ 를 **즉시** 교환해 위상 변화를 억제한다(동기화 토크).
- GB GC0137은 위상 점프 응답을 핵심 요건으로 두고, 설계 위상 점프 각(예: ±5°~±60° 범위, 구체값 문서 확인)과 그때의 전력·전류를 규정한다.
- 하드웨어: 위상 점프 시 전류가 급증하므로 전류 제한과 묶여 설계. 큰 점프에서는 제한에 걸려도 "전압원처럼" 거동해야 한다.

## 4. 고장 전류 기여 (Fault Current Contribution)

- 전압 강하 즉시 $(E - V)/Z$ 전류가 흐르고 제한기가 개입. 제한 전류 내에서 무효(역상 포함) 전류 공급.
- 동기기 대비 작은 크기(1.2~2 pu)이므로 보호 설계에 **단락전류 기여 데이터**를 제공해야 한다. → [전류 제한과 고장 대응](03-전류제한-고장대응.md)

## 5. 댐핑 (Damping)

- 동기기 진동 모드(0.1~2 Hz), 아임계(5~45 Hz), 제어 상호작용(수십~수백 Hz)에 양의 댐핑을 제공.
- 계통운영자는 EMT 모델로 댐핑비 평가(예: AEMO ≥ 0.05 등 지역 기준). GFM 제어 파라미터(D, 가상 저항)로 조정.

## 6. 계통강도 제공 (System Strength)

- 저주파 대역 출력 임피던스가 낮고 유도성 → 테브난 등가 임피던스 감소 → 주변 GFL의 유효 SCR 상승.
- 호주 NEM은 GFM BESS를 system strength 서비스 자원으로 인정(동기조상기 대안). 정량화는 EMT 기반 개별 평가.

## 7. 블랙스타트 (Black Start)

- 순서: 보조전원 → GFM 기동(무부하 전압 형성) → 변압기 여자(소프트 스타트로 돌입전류 억제) → 선로 충전 → 부하 블록 투입 → 다른 발전기 동기투입.
- 요구 사항: 자체 기동 보조전원, 수 시간 이상 지속 가능한 에너지, 돌입전류 대응(전압 램프업), 보호·통신 체계.
- 영국은 ESO 블랙스타트(Electricity System Restoration) 조달에 배터리 참여를 허용, 호주·미국에도 GFM BESS 블랙스타트 실증 사례 다수. → [해외 프로젝트](../06-실증-사례/01-해외-프로젝트.md)

## 8. 단독운전과 재동기

- 계통 분리 후 GFM이 V/f를 유지(마이크로그리드 마스터). 부하·발전 균형을 ESS가 흡수.
- 재동기: 전압 크기·주파수·위상 차를 허용 범위 안에 맞춘 뒤 동기 차단기 투입. GFM의 $\omega_0$, $E_0$ 설정값을 천천히 조정.
- 의도치 않은 단독운전(배전 계통)은 반대로 **검출·정지**가 요구되므로 GFM 배전 연계 시 보호 규정과의 정합이 필요하다 (IEEE 1547 단독운전 검출 요건과의 관계).

## 9. 고조파·불평형 흡수

- 전압원은 전류제어 대역 밖 성분(고조파·역상)을 수동적으로 흡수해 전압 품질을 개선한다. 다만 열·전류 여유를 소모하므로 흡수량 제한 루프를 둔다.

## 10. 기능별 하드웨어 요구 정리

| 기능 | 과부하 여유 | 에너지 (ESS) | 추가 장치 |
|---|---|---|---|
| 관성·위상점프 | 1.2~1.5 pu / 수 초 | 작음 (MW·s 단위) | — |
| 고장 전류 | 1.2~2 pu / 수백 ms | — | 보호 협조 |
| 블랙스타트 | 변압기 돌입 대응 | 수 시간 | 보조전원, 동기장치 |
| 단독운전 | 부하 돌입 | 수 시간 이상 | 동기장치, 통신 |
